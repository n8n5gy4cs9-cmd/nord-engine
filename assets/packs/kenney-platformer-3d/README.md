# Kenney 3D Platformer Kit (optional CC0 pack)

Source: https://github.com/KenneyNL/Starter-Kit-3D-Platformer @ 3fa8a04b1c01ab23db43123d4ce814a34c3fc7f0
Assets (3D models, sprites, sound effects): **CC0** by Kenney (https://kenney.nl). The kit's Godot code is MIT and is not included.
Contents: `models/*.glb` (character, coin, platforms, flag, cloud, grass, brick, dust + `Textures/colormap.png`),
`sounds/*.ogg` (jump, land, fall, walking, coin, break), `sprites/*.png` (coin, particle, blob_shadow, skybox).
Refetch: `tools/fetch-packs.sh`. Use in a project by copying files into its `assets/`.
