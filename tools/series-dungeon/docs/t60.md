## 1 How 2D light works in Nord

Nord does not ship lighting inside the renderer for 2D. It comes as three small, readable **library scripts** that you copy into your project (open the @ui[Library] tab, category *fx*, or copy the files from `library/scripts/`). That is a feature: you can open them, read them and change them.

| Script | Goes on | Does |
|---|---|---|
| `light2d.js` | **one** empty entity | draws the darkness (a small *lightmap* multiplied over the game) and keeps the list of lights and occluders |
| `light2d-source.js` | anything that glows | a point light or a cone: colour, intensity, radius, falloff, flicker |
| `light2d-occluder.js` | walls, crates, pillars | blocks light: casts shadows |

Sprites on **layer 1 and above**, and the HUD, are drawn after the darkness and stay bright. Layer 0 is darkened.

## 2 Adding the scripts

1. Copy `light2d.js`, `light2d-source.js` and `light2d-occluder.js` into `scripts/`.
2. Create an empty entity `Light2D` and attach `light2d.js`. Set **ambient** to a very dark blue `#0a0c12` (the colour of "no light"), `scale` 7.5 (the lightmap is 1/7.5 of the screen resolution: blurry and fast), `shadows` on.
3. Make a child entity `Lantern` of the hero (drag it onto `Hero` in the Hierarchy) and attach `light2d-source.js`: `color` `#ffb86b`, `radius` 190, `intensity` 0.9, `falloff` 1.4, `softness` 5, `flicker` 0.08.

Because `Lantern` is a **child**, it moves with the hero, nothing else to write. Play: the world is black except for a warm circle.

## 3 Walls that cast shadows

The light goes through walls until they carry the occluder script. The `Level` script from part 5 only changes in one place, the wall entity gets a script:

```js
await this.scene.spawnData(data('Wall', ['solid'], col * t + w / 2, row * t + t / 2, 1, [
  sprite(w, t, '#4c566a'), { type: 'rigidbody', mode: 'static' }, { type: 'collider', shape: 'box', size: [w, t] },
], [{ path: 'scripts/light2d-occluder.js', attributes: { static: true } }]));   // this wall now blocks light
```

`static: true` tells the occluder the wall never moves, so it computes its shadow edges once.

Press **Play**. Stand in a room, then walk to a corridor mouth: the lantern lights the room, and the wall casts a shadow, so you cannot see what is behind it. Enemies in the dark are invisible until they step into the light: the "unfair" see-through chase of part 5 suddenly feels like a horror game.

> **Why did merging the walls in part 3 matter?** Every occluder adds edges that light has to be tested against. 74 long strips are far cheaper than 449 squares. The shadow code lives in `light2d.js`; read the `castRay` and `clear` functions at its top if you want to see how a ray is tested against the wall edges.

## 4 Asking the light

The lighting system exposes itself as `game.light2d`, so gameplay can ask **how bright is it here**:

```js
const p = this.entity.worldPos;
const level = this.game.light2d.lightAt(p[0], p[1]);   // 0 = dark, about 1 = fully lit, shadows included
```

Stealth games, vampires, plants that grow in the light: all of them start from this one number. The test for this tutorial asserts that the hero stands in light (more than 0.5) and a point 400 pixels away is dark (less than 0.05).

## 5 The rest of the file did not change

`hero.js`, `enemy.js`, `health.js`, `hud.js`, `coin.js` and `follow.js` are the files of part 5. A good game architecture shows here: we added a whole visual system and touched one line of the level script.

## 6 Shipping

Check the project, then build it:

```bash
nord check dungeon
nord build dungeon --minify -o dungeon-web          # a folder of static files: upload it anywhere
nord build dungeon --single-file -o dungeon-one     # ONE index.html: send it by e-mail, it runs from file://
nord build dungeon --zip --host itch -o dungeon-itch  # also writes dungeon-itch.zip, ready for itch.io
```

The folder contains the runtime, the engine libraries and your scenes and scripts. No server and no internet are needed to play it. Open `index.html` in a browser (or, for the multi-file build, host the folder: browsers only allow modules over `http://`).

Our part 6 build is 2.8 MB of files, 1.3 MB as a zip, most of it the Phaser library.

## 7 Check yourself

* Dark world, warm circle around the hero, soft edge.
* A wall between you and an enemy hides it.
* `ambient` `#000000` makes the corners pitch black, `#3a3f55` makes the whole map readable.
* The exported folder plays from a static web server (try `python3 -m http.server` inside it).

## What you learned

* 2D light is three library scripts: system, source, occluder.
* A child entity follows its parent: a lantern is a child of the hero.
* `game.light2d.lightAt(x, y)` turns light into game logic.
* `nord build` exports a static web game: folder, single file, zip, hosting presets.
