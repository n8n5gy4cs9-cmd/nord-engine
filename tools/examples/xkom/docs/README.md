# X-KOM 2026

Example game: **X-COM-style campaign + Red Alert-style RTS boss operation.** Rotatable textured globe with HQ regional zoom, compact textured command UI, illustrated title screen, base research, skippable UFO interception (radar + Star Fox-style shooter), procedural isometric turn-based missions with time units / reaction fire / fog of war — and when alien presence reaches 100 % the hive strikes: a real-time base-vs-hive operation. Defend six towns as opposition escalates, gather intel, research Elerium, then win a Source Raid and final Hive assault to finish the war. P/Esc opens pause with Save/Load; title Continue restores a campaign checkpoint at HQ.

Open `GUIDE.md` for controls and rules, `assets.md` for every picture/sound and how to replace it.
Crowelian 2026 + Sonnet.
