# Assets — Midnight Sun Tour

All files were made for the original NordScrap game by the author and are reused unchanged.

| Folder | Contents |
|---|---|
| `assets/sprites/` | 98 PNGs: title art, band portraits and sprites, bus (side/top-down/night/broken), painted Finland map, encounter illustrations, minigame sprites, UI sheets, ending art |
| `assets/music/` | 22 MP3 loops (title, overworld day/night, city, sauna, each minigame, festival good/bad, game over) |
| `assets/music/band_music/` | 6 live-set recordings used at Ruisrock (BJM, Aldous Harding, Burial, Islaja, Karhumauri, Queen) — **these are third-party recordings; clear the rights before publishing the export** |
| `assets/sfx/` | 40 MP3 sound effects (bus, crowd, UI, minigames) |
| `assets/fonts/vt323.woff2` | VT323 (OFL), the text font; the original NordScrap bitmap font was not portable |

Paths are in `scripts/game/game_constants.js` (`MUSIC`, `SFX`, `SPRITES`, `BAND_MUSIC`). Missing files are silent, as in the original.
