# Vallout 2: New Kerava
Comic Fallout-2-style RPG in alien-fallout Kerava, Finland. Built on [nord-engine](https://github.com/n8n5gy4cs9-cmd/nord-engine) (Phaser). Original pixel art + synthesized audio.
Run: `nord serve examples/vallout` (or open it from the editor hub). Rules: `GUIDE.md` · Assets: `assets.md`
