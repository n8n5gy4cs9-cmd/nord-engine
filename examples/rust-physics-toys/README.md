# Rust physics toys
Click or press Space to drop boxes into a rapier2d world (R resets). Shows the Rust `Script` trait, `Registry::prefab`, `spawn_prefab`, events and attributes.
Run: `nord build-rust . && nord serve .` (or ▶ Play in the editor). Export: `nord export . --target web-wasm-game`. See docs/RUST_TIER.md.
