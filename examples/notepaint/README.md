# notepaint
A complete offline notebook: each document has text and a drawing. New/rename/search/duplicate/delete, autosave, pencil/brush/eraser/fill/line/rectangle/ellipse/picker, undo/redo, text/image import, portable document import/export, TXT/PNG downloads.

Open with `nord serve examples/notepaint`. See GUIDE.md, assets.md and the manual tutorial. Source: `tools/examples/notepaint/`; regenerate with `node tools/gen_examples.mjs notepaint`. No external dependencies. Crowelian 2026 + Sonnet.
