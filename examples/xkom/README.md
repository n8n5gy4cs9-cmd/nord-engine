# X-KOM 2026

Example game: **X-COM-style campaign + Red Alert-style RTS boss operation.** Flat geoscape, base research, skippable UFO interception (radar + Star Fox-style shooter), procedural isometric turn-based missions with time units / reaction fire / fog of war — and when alien presence reaches 100 % the hive strikes: a real-time base-vs-hive operation. Win by killing enough aliens.

Open `GUIDE.md` for controls and rules, `assets.md` for every picture/sound and how to replace it.
