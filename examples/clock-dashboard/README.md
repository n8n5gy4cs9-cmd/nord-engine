# Clock Dashboard

Asset bundles in practice (docs: Examples page 3.7, `docs/ASSET_BUNDLES.md`). `bundles/analog-clock.nordpkg` and `bundles/digital-clock.nordpkg` were exported from `examples/clock` and `examples/digital-clock` with `nord bundle export`, imported with `nord bundle import`, and the two prefabs placed in `scenes/main.scene.json`.
Re-run: `nord bundle import bundles/analog-clock.nordpkg --replace` (same for the digital clock).
