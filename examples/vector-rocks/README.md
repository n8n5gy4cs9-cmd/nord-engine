# Vector Rocks

Asteroids on an old green XY vector monitor, written Unity-style (MonoBehaviour, Singleton, Instantiate, coroutines, triggers). Controls: A/D or arrows turn, W/Up thrust, Space fire, Shift hyperspace. Power-ups: shield, rapid fire, triple shot, nova, extra life.
Art: `python3 tools/gen_vector_rocks_art.py`. Project: `python3 tools/make_vector_rocks.py`. Page: examples page 44.
