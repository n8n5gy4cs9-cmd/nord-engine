# Star-Not
A complete small solar-system adventure. Earth-race, Mars-race and Venutians; eight planets and the Sun; diplomacy, resources, wrapping ship combat, planetary checkpoints, portable saves, victory and defeat. Optional shared-keyboard or P1 keyboard + P2 gamepad combat co-op.

Start with `nord serve examples/star-not`, or open it in NordEditor. Read GUIDE.md for the route and controls; assets.md lists reusable original art/audio. Source: `tools/examples/star-not/`; regenerate with `node tools/gen_examples.mjs star-not`. GPL-2.0-or-later game code (small UQM normal-thrust adaptation); original assets. Crowelian 2026 + Sonnet.
