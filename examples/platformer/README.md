# Platformer
A/D or arrows run, Space/W jump (variable height, coyote time), Shift/K dash. Stomp slimes; the big slime at the end is the boss (5 stomps). Flags are checkpoints; falling respawns you.
Built almost entirely from library scripts (`platformer2d`, `health`, `pickup`, `ai-patrol`, `checkpoint`, `camera-follow`, `ui-hud`, `score`) plus two small scripts: `enemy.js`, `boss.js`.
