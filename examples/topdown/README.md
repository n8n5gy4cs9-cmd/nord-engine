# Top-down adventure
WASD/arrows move, E talks / opens the chest / attacks, I opens the inventory. Find the key, open the door, avoid bats, reach the chest.
Library scripts: `topdown`, `health`, `inventory`, `dialogue`, `pickup`, `ai-chase`, `key-door`, `camera-follow`, `ui-*`. Own scripts: `npc.js`, `item.js`, `chest.js`, `enemy-hp.js`, `hero-anim.js`.
