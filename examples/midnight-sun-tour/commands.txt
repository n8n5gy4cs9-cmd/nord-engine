MIDNIGHT SUN TOUR — private developer reference
Open/close: F2 or backquote. ESC closes. Up/down recalls commands.
The game stops while the console is open. No hints or command lists appear there.
Commands are case-insensitive. No JavaScript/eval is accepted.

state                       Current scene, resources, bus, journey, cheat flags.
clear                       Empty console output.
new                         Fresh tour at gear packing.
god [on|off]                Toggle invulnerable bus/crew and arcade health;
                            refill fuel/food/morale; retain >=10000 cash/festival budget and >=7 days.
                            Timers still run. Use win to finish a challenge.
freeze [on|off]             Lock the remaining journey days; minigame timers run.
refill                      Repair/refuel; feed crew; restore morale and band.
rich                        Refill plus 1000000 FIM, 100 hype and 100 fame.
gear                        Pack every equipment item immediately.
set cash <0..10000000>       Set absolute cash, not an increment.
set food <0..10>
set morale <0..100>
set hype <0..100>
set gas <0..tank capacity>
set condition <0..100>
set days <1..365>
set fame <0..100>
set budget <0..10000000>     Set the active Ruisrock management budget.
save                        Save persistent journey checkpoint (not arcade progress).
load                        Load checkpoint on overworld; restarts festival if revisited.

FESTIVAL / ENDINGS
festival <phase> [day]       Jump to phase on day 1..3 (default 1).
Phases: intro book grounds staff simulate report results
Grounds: G/ESC returns to booking. Other management controls are in GUIDE.md.
Staff/simulate/report jumps create a free Mikko-only lineup, avoiding stale bookings.
win                         Complete current minigame successfully; close the console
                            and press ENTER to collect its reward and continue.
                            In packing, immediately continue with all gear.
                            In festival, show a perfect final festival result.
                            Elsewhere, jump to a perfect Ruisrock ending.

  new

  goto city turku

Flags last for this running session and are not included in checkpoints.
Turning god off stops resource refills; resources already granted are kept.
