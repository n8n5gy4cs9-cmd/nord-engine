## Showcase games (M6 examples)
- **RetroPaxDungeons** (`examples/retropaxdungeons`): rules/AI/FOV/level-patch logic ported from Shattered Pixel Dungeon (https://github.com/00-Evan/shattered-pixel-dungeon, GPL-3.0). Art original. Example is GPL-3.0.
  Its field-of-view source also cites RogueBasin's [FOV using recursive shadowcasting](http://www.roguebasin.com/index.php?title=FOV_using_recursive_shadowcasting). This citation was moved from the JS comment here so the offline URL scanner does not treat it as a runtime request.
- **Noom** (`examples/noom`): `P_Random` table, monster AI, damage formulas ported from id Software DOOM (https://github.com/id-software/doom, GPL-2.0); setting inspired by Barony (https://github.com/TurningWheel/Barony, GPL-3.0; no code/art used). Art original. Example is GPL-2.0-or-later.
- **Altimu 5.7** (`examples/altimu`): design/behaviour modelled on Ultima V as re-implemented by `synthwave-pixel/ultima5` (MIT; day/dawn/dusk hours, 4-letter keyword stubs, learned-word list, separate battle arena) and on Exult / the Ultima VII decompilation (`exult/exult` GPL-2.0, `Kitrinx/Ultima7_Decomp`) for names and story context only. **No code, data, text or art from those projects or from Origin/EA is included**; all dialogue, art and the Trinsic map are original. Importing the real map from the owner's own copy is documented in `examples/altimu/GUIDE.md`.
- **Harrison's Command** (`examples/harrison`): Kenney Starter Kits (MIT, https://github.com/KenneyNL/Starter-Kit-FPS, -City-Builder, -Racing, -3D-Platformer: models + a few sounds, copied as-is), movement constants ported from Starter-Kit-FPS `objects/player.gd`; weapon/structure/body numbers from Warzone 2100 `data/mp/stats/*.json` (GPL-2.0+, subset in `scripts/hc/wz-stats.json`; the example is therefore GPL-compatible); split-screen layout ported from the owner's `n8n5gy4cs9-cmd/nordrep` (`src/core/split.rs`). Carrier, Walrus, Manta, towers and islands are generated (`tools/gen_harrison_models.mjs`); textures/icons hand-pixelled.
- **Forgotten Wars** (`examples/forgotten`): rules modelled on the publicly documented *Advance Wars 2* model (terrain stars, move types, HP-scaled damage, counter-attacks, capturing — game mechanics only). `Eebit/aw2bhr` (an assembly decompilation whose data sections are still `.incbin "baserom.gba"`) was cloned and read; **no code, data, text or art from it or from Nintendo / Intelligent Systems is included**. Army/unit/map names, all 16×16 art (`tools/art/forgotten`, hand-pixelled), the map and the AI are original; font shared with Noom/Altimu; sounds are Nord placeholders.
- **Automies** (`examples/automies`): handling model ported from OpenDriver2/REDRIVER2 (https://github.com/OpenDriver2/REDRIVER2, GPL-2.0): `src_rebuild/Game/C/wheelforces.c` (`GetFrictionScalesDriver1`, `AddWheelForcesDriver1`, `ConvertTorqueToAngularAcceleration`), `handling.c` (`ProcessCarPad`, `GlobalTimeStep` integration), `gamesnd.c` (`geard`, `GetEngineRevs`, `ControlCarRevs`), `camera.c` (`PlaceCameraFollowCar` constants) → `scripts/am/car.js` (the example is therefore GPL-2.0-compatible). No Driver 2 data/models/sounds are included. Kenney Starter Kits (MIT, https://github.com/KenneyNL/Starter-Kit-City-Builder and -Racing: roads, buildings, trucks, `engine/skid/impact/ambience.ogg`, copied as-is by `tools/fetch-automies-assets.sh`). Split-screen layout `scripts/am/split.js` is the nordrep port (same file as Harrison's). Cars, towers, landmarks, props are generated (`tools/gen_automies_models.mjs`); textures and HUD icons hand-pixelled (`tools/art/automies`); siren and horn are synthesised at run time.
- **X-KOM 2026 / Red Front 2026** (`examples/xkom`, `examples/redfront`): rules/numbers adapted from OpenXcom (https://github.com/OpenXcom/OpenXcom, GPL-3.0: `bin/standard/xcom1/items.rul` rifle + plasma stats, `units.rul` sectoid/muton, `armors.rul`, `src/Battlescape` TU costs / hit and damage / reaction-fire logic → `scripts/xk/tactical.js`), OpenRA (https://github.com/OpenRA/OpenRA, GPL-3.0: `mods/ra/rules` cost/HP/speed/range of E1, E3, 1TNK, 2TNK, HARV, FACT, POWR, BARR, WEAP, PROC, PBOX; grid A* idea from `OpenRA.Mods.Common/Pathfinder` → `scripts/xk/rts.js`) and the EA CnC Remastered source (https://github.com/electronicarts/CnC_Remastered_Collection, GPL-3.0, read as a rules reference only). The examples are therefore GPL-3.0-compatible. **No art, sound or data files from those projects** — X-KOM sprites are original ImageGen-assisted raster art plus hand-pixelled details (`tools/art/xkom/redrawn`, exact prompts included, and `details.mjs`); Red Front sprites remain hand-pixelled (`tools/art/xkom/rts.mjs`); all audio synthesized (`tools/gen_xkom_audio.mjs`). The interception shooter only takes the idea of a short Star Fox-style sequence (nothing from StarFoxSNESRecomp or Nintendo).
- **Fonts for X-KOM 2026 / Red Front 2026**: VT323 (https://github.com/phoikoi/VT323, Google Fonts, OFL-1.1) and Orbitron (https://github.com/theleagueof/orbitron, Google Fonts, OFL-1.1) via `@fontsource/vt323` and `@fontsource/orbitron` 5.3.0 (vendored by `tools/vendor.mjs`, copied into `examples/{xkom,redfront}/assets/fonts/`; licences next to the files). Pixelify Sans is vendored too (`vendor/fonts/pixelify-sans`, OFL-1.1) but currently unused.

### X-KOM mission layout reference (M6-36)
OpenXcom/OpenXcom at `4a4bae5fa2e5a09282928e84943fc84b093e34ff` (GPL-3.0), `bin/standard/xcom1/terrains.rul` and `src/Battlescape/BattlescapeGenerator.cpp` (`generateMap`, `selectPosition`, `addBlock`) were studied for terrain-block assembly and placement. `tools/examples/xkom/scripts/xk/tactical.js` uses original farmland/settlement/depot/woodland geometry, rotated/mirrored deployment zones and reachability checks. No OpenXcom map data, graphics, sounds or generator code were copied in this change; original X-COM resources are not bundled.

- **Vallout 2: New Kerava** (`examples/vallout`): combat/skill formulas (to-hit, damage, derived stats) re-implemented from the publicly readable rules of `fallout2-ce` (`src/combat.cc attackDetermineToHit`, `stat.cc`, `skill.cc`; Sustainable Use License) — formulas only, **no code or assets copied**; sfall/falltergeist are reference only. The bitmap font `font.png` and `pixeltext.js` are copied from the engine's `forgotten`/Altimu example. All art (`tools/art/vallout`, hand-typed) and audio (`tools/gen_vallout_audio.mjs`) are original.
