A 3D scene needs something to look at and a camera to see it. Nord components create the models, materials and lights in Babylon for you.

::: dummies
Start with a box, a camera pointed at it and a light. Press Play before adding an imported model. If the box is missing, check the camera before changing the material.
:::

3D projects (`"type": "3d"`) run on Babylon.js with Havok physics. Units are metres, **y up, left-handed**; rotation is Euler degrees (XYZ).

::: dummies
3D is the same entity-and-component idea, plus a third direction: **y** is *up*, **z** is *forward*. A "mesh" is the shape,
a "material" is its paint, a "light" lets you see it.
:::

## Building blocks
* [`mesh`](component-mesh.html) — box, sphere, cylinder, capsule, torus, plane, ground. Perfect for greyboxing.
* [`model`](component-model.html) — a glTF/GLB. Models are instanced; animations are named clips (`play('walk')`).
* [`material`](component-material.html) — PBR: `color`, `metallic`, `roughness`, textures, `emissive`, `alpha`, `unlit`.
* [`light`](component-light.html) — directional (sun), point, spot, hemispheric (ambient sky). `castShadows` on a directional/spot light enables shadows for everything with `castShadow`.
* [`skybox`](component-skybox.html) — cube map folder (`assets/skybox/day`, `sunset`, `night` ship with the engine).
* [`postProcess`](component-postProcess.html) — bloom, FXAA/MSAA, vignette, tonemap, grain.
* [`particles`](component-particles.html) — Babylon particle system with the same component name as 2D.

## Material assets

A `*.mat.json` file in `assets/` (Assets ▸ Create ▸ Material) is a shared material: `color, metallic, roughness, texture, normalMap, emissive, emissiveMap (a picture that glows), alpha, uvScale, uvOffset, doubleSided, unlit`. Select the file to edit it in the Inspector (with a quick preview), and point a `material` component's **asset** field at it; every mesh using it shares the values. Image import settings (Inspector on a selected image): **filter** `nearest` for crisp pixels and **wrap** `clamp`, stored in the sidecar `<image>.meta.json`.

## Cameras
A [`camera`](component-camera.html) entity creates a Babylon camera: `type: "orbit"` (follows `follow`, optional mouse control) or a free camera attached to the entity (first person: put the camera as a child of the player body).
Switch with `getComponent('camera').activate()`. Library: `fps3d.js`, `third-person3d.js`, `orbit-cam.js`, `fly-cam.js`, `rts-cam.js`.

## Animation
`model.play(name, { loop, speed })`. Clip names come from the glTF; `getComponent('model').animations` lists them. Blend by switching clips with short tweens on speed if you need to.
The Kenney pack in `assets/packs/kenney-platformer-3d/` has a rigged character to experiment with ([Assets](assets.html#optional-packs)).

## 3D UI
Use the DOM layer (`game.ui`, see [UI](ui.html)) for HUDs. For labels floating above entities, `game.gui.worldLabel(entity, 'Bob')` (Babylon GUI).

## Picking and rays
`game.physics.raycast(from, to, { ignore })` returns the first physics hit with the entity. The library has `interact-ray.js` and `physics-hitscan.js`.

## Performance tips
Reuse materials and models (instancing is automatic), keep shadow map size modest (1024 default), prefer one directional light with shadows, and use `postProcess` sparingly on laptops.
See [Performance](performance.html).
