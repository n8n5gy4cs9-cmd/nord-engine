GIRSMManager #

export class GIRSMManager

Pure barrel — re-exports only side-effect-free modules This file must only contain pure code and pure imports Reflective Shadow Maps were first described in (online reference) by Carsten Dachsbacher and Marc Stamminger Further explanations and implementations can be found in:

  • Jaker video explaining RSM and its implementation: (online reference)
  • C++ implementation by Luis Angel: (online reference)
  • Javascript implementation by Erkaman: (online reference)

Class used to manage the global illumination contribution calculated from reflective shadow maps (RSM).
