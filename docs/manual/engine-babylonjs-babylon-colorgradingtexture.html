ColorGradingTexture #

export class ColorGradingTexture extends BaseTexture

This file must only contain pure code and pure imports This represents a color grading texture. This acts as a lookup table LUT, useful during post process It can help converting any input color in a desired output one. This can then be used to create effects from sepia, black and white to sixties or futuristic rendering...

The only supported format is currently 3dl. More information on LUT: (online reference)
