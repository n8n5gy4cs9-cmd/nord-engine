TintModes #

enum TintModes

Phaser Tint Modes.

Tint modes are used by the Tint component to determine how the tint color is applied to the texture. The default mode is MULTIPLY. They are only used in WebGL.

Public members (7)

Private, protected and explicitly internal declarations are excluded. Inherited members belong to the base type listed in the declaration.

MULTIPLY #

MULTIPLY

Multiply tint mode (default). The tint color is multiplied with the texture color.

FILL #

FILL

Fill tint mode. The tint color replaces the texture color, but respects the texture alpha.

You can use this mode to make a Game Object flash 'white' if hit by something.

ADD #

ADD

Additive tint mode. The tint color is added to the texture color, but respects the texture alpha.

SCREEN #

SCREEN

Screen tint mode. The tint color brightens dark areas of the texture.

OVERLAY #

OVERLAY

Overlay tint mode. The tint color brightens light areas and darkens dark areas.

HARD_LIGHT #

HARD_LIGHT

Hard light tint mode. The tint color brightens light areas and darkens dark areas. This is like overlay, but with the tint color and texture color swapped.

MULTIPLY_TWO #

MULTIPLY_TWO

Double color multiply tint mode. The tint color is multiplied with the texture color, and the inverse of the texture color is multiplied by a second tint color. This allows control of light and dark regions separately.
