ChannelMask #

export enum ChannelMask

Bitmask controlling which channels are written to the output texture by a processing operation. Channels excluded from the mask receive a sensible default: 0.0 for RGB channels, 1.0 for alpha. Use ChannelMask.RGBA (or omit the parameter) to pass all channels through unchanged.

Flag Channels written Excluded channels
R red G=0, B=0, A=1
G green R=0, B=0, A=1
B blue R=0, G=0, A=1
A alpha R=0, G=0, B=0
RGB red, green, blue A=1
RGBA all four (none)
