useMipMaps #

get useMipMaps(): Nullable<boolean>;

Indicates to use the mip maps (if available on the texture). Thanks to this flag, you can instruct the sampler to not sample the mipmaps even if they exist (and if the sampling mode is set to a value that normally samples the mipmaps!) If useMipMaps is null, the value of generateMipMaps is returned by the getter (for backward compatibility)

Type / return: Nullable<boolean>
