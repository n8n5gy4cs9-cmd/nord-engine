ReflectionBlock #

export class ReflectionBlock extends ReflectionTextureBaseBlock

Re-exports pure implementation and applies runtime side effects. Import refractionBlock.pure for tree-shakeable, side-effect-free usage.

This file must only contain pure code and pure imports Block used to implement the reflection module of the PBR material
