LogLevels #

static set LogLevels(level: number);

Sets the current log level. This property is a bit field, allowing you to combine different levels (MessageLogLevel / WarningLogLevel / ErrorLogLevel). Use NoneLogLevel to disable logging and AllLogLevel for a quick way to enable all levels.
