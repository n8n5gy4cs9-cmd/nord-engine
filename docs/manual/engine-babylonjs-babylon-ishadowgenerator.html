IShadowGenerator #

export interface IShadowGenerator

Interface to implement to create a shadow generator compatible with BJS.

Public members (12)

Private, protected and explicitly internal declarations are excluded. Inherited members belong to the base type listed in the declaration.

id #

id: string;

Gets or set the id of the shadow generator. It will be the one from the light if not defined

Type / return: string

doNotSerialize #

doNotSerialize?: boolean;

Specifies if the ShadowGenerator should be serialized, true to skip serialization. Note a ShadowGenerator will not be serialized if its light has doNotSerialize=true

Type / return: boolean

getShadowMap #

getShadowMap(): Nullable<RenderTargetTexture>;

Gets the main RTT containing the shadow map (usually storing depth from the light point of view). returns The render target texture if present otherwise, null

Type / return: Nullable<RenderTargetTexture>

isReady(subMesh: SubMesh, useInstances: boolean, isTransparent: boolean): boolean;

Determine whether the shadow generator is ready or not (mainly all effects and related post processes needs to be ready). param subMesh The submesh we want to render in the shadow map param useInstances Defines whether will draw in the map using instances param isTransparent Indicates that isReady is called for a transparent subMesh returns true if ready otherwise, false

bindShadowLight #

bindShadowLight(lightIndex: string, effect: Effect): void;

Binds the shadow related information inside of an effect (information like near, far, darkness... defined in the generator but impacting the effect). It implies the uniforms available on the materials are the standard BJS ones. param lightIndex Index of the light in the enabled light list of the material owning the effect param effect The effect we are binding the information for

getTransformMatrix #

getTransformMatrix(): Matrix;

Gets the transformation matrix used to project the meshes into the map from the light point of view. (eq to shadow projection matrix * light transform matrix) returns The transform matrix used to create the shadow map

Type / return: Matrix
