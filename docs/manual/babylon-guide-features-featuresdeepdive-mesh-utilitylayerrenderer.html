Babylon guide: Rendering Utility Layers

Official Babylon guide · source snapshot

Read this as an underlying-engine guide

UtilityLayerRenderer#

The UtilityLayerRenderer class overlays objects in a scene without modifying the existing scene. It can be used to enable custom overlays or Gizmos.

The default utility layer renderers are available as follows:

UtilityLayerRenderer.DefaultUtilityLayer; // for overlays like position/scale gizmos
UtilityLayerRenderer.DefaultKeepDepthUtilityLayer; // for occluded gizmos like bounding box)

Utility layers can also be created manually:

const utilLayer = new BABYLON.UtilityLayerRenderer(scene);

The UtilityLayerRenderer contains references to both the utility layer's scene as well as the original scene.

utilLayer.originalScene;
utilLayer.utilityLayerScene;

Once created, meshes can be added to the utility layer's scene:

// Create an overlay box
const overlayBox = BABYLON.MeshBuilder.CreateBox("box", { size: 1 }, utilLayer.utilityLayerScene);
overlayBox.position.z = 0.5;
overlayBox.position.y = 3.5;
// Create a different light for the overlay scene
const overlayLight = new BABYLON.HemisphericLight("light1", new BABYLON.Vector3(0, 0, 1), utilLayer.utilityLayerScene);
overlayLight.intensity = 0.7;

Controls#

By default, the overlaid scene will be drawn on top of the existing scene, ignoring the depth buffer. If objects in the utility scene should be occluded by the main scene, autoClearDepthAndStencil should be set to false.

utilLayer.utilityLayerScene.autoClearDepthAndStencil = false;

Note: When this is set to false, transparent meshes will always be occluded by objects drawn to the utility layer. By default, the utility layer's scene will be drawn after every draw of the original scene. To disable this behavior, the shouldRender property can be set to false. If set to false, the utility layer can be rendered manually via the render function.

utilLayer.shouldRender = false;
utilLayer.render();

Pointer events#

Since the utility layer is rendered on top of the existing scene, there are a couple of options to control how pointer interactions with the scenes work. By default, the utility layer fires the pointerUp, pointerDown, and pointerMove events as usual, but pointerDown events are passed to the utility layer's scene only if the pointer event hits it first.

To disable other events when the pointer event does not contact the utility layer first, use the following:

utilLayer.onlyCheckPointerDownEvents = false;

To enable all events beyond up, down, and move (e.g. mouse wheel), set processAllEvents.

utilLayer.processAllEvents = true;

The UtilityLayerRenderer fires an onPointerOutObservable event when the pointer leaves the utility layer back to the original scene.

utilLayer.onPointerOutObservable.add(function (pointerId) {});
