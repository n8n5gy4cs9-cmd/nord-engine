InputBlock #

export class InputBlock extends NodeMaterialBlock

Re-exports pure implementation and applies runtime side effects. Import prePassTextureBlock.pure for tree-shakeable, side-effect-free usage.

This file must only contain pure code and pure imports Block used to expose an input value
