Transformations#

Target Axes Alignment#

When you want to rotate a mesh (or a camera) so that it lines up with a given set of axes, you can use the RotationFromAxis method as follows:

var orientation = BABYLON.Vector3.RotationFromAxis(axis1, axis2, axis3);
mesh.rotation = orientation;

where axis1, axis2, and axis3 are three left-handed orthogonal vectors, and the mesh will be aligned with

  • axis1 as the x axis in its local space
  • axis2 as the y axis in its local space
  • axis3 as the z axis in its local space

Align Plane to Curve#

At any point along a curve in 3D space, the tangent, normal, and binormal form a set of orthogonal axes; call these the point axes. A plane created in Babylon.js has a normal along the z axis, with the x and y axes lying in the plane. We can draw a curve in space using an array of position vectors. By creating a 3D path from this curve, we can obtain the normal, tangent, and binormal of the curve at each of the positions that define it. Using RotationFromAxis, we can align the x, y, and z axes of the plane with the point axes of the curve. There are 6 ways to order a group of three axes, and therefore 6 ways to align the plane axes to the curve point axes.

All six ways are used in the playground below. The top one [0] has the plane tangential to the curve and the fourth one down [3] is perpendicular to the curve. Others can twist the plane at certain points.

Refining Alignment#

To help understand which of the 6 possible arrangements to use, it is useful to show the axes of the mesh that you want to follow the line, along with the tangents, normals, and binormals of the path.

For example, we want a cone to follow along a path with its point first, and with the height axis of the cone tangent to the path.

Below is an image showing the cone axes and the path tangents, normals, and binormals at the start of the path, before any alignment with the path takes place.

Upstream illustration: Align Axes (media not bundled).

Our example requires the y axis of the cone to lie along the tangents of the path. Placing the x axis of the cone along the normals of the path would leave the z axis pointing in the opposite direction to the path binormals. This gives us the y axis along the tangents, the x axis along the binormals, and the z axis along the normals. This is option 4.

new BABYLON.Vector3.RotationFromAxis(binormals[p], tangents[p], normals[p]);

Align Camera#

Given two spheres, draw a plane between them that always faces the camera. We are going to set up red and green spheres, world axes shown as red, green, and blue lines, and a purple plane in the xz plane. Joining the red and green spheres is a plane with a blue arrow on it pointing from the green sphere to the red sphere.

The requirement is for the arrow plane to rotate such that

  • one of its orthogonal axes that lies on the arrow is along the line joining the two spheres;
  • the other axis lying on the arrow plane is perpendicular to the camera lens;
  • the axis normal to the plane is along the line joining the middle of the arrow to the camera.

In this way, the camera always faces the arrow plane, as can be seen in this playground.

Online playground (not embedded offline)

This is achieved by forming axis 1 to join the spheres, axis 3 to be perpendicular to axis 1 and to the axis through the camera position, and axis 2 to run from the camera to the arrow plane:

axis1 = (sphere1.position).subtract(sphere2.position);
axis3 = BABYLON.Vector3.Cross(camera.position, axis1);
axis2 = BABYLON.Vector3.Cross(axis3, axis1);

The mesh is rotated to face the camera using:

mesh.rotation = BABYLON.Vector3.RotationFromAxis(axis1, axis2, axis3);

Using Quaternions#

If you prefer using quaternions instead of Euler angles, then RotationQuaternionFromAxis() computes the required rotation quaternion to assign to the mesh property rotationQuaternion.
