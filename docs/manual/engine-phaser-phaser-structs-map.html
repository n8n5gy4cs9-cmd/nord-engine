Map #

class Map<K, V>

A custom Map implementation that stores entries as key-value pairs with ordered iteration. Unlike a native JavaScript Map, it also maintains an internal array of entries for efficient indexed access and iteration. Supports filtering, merging, and contains/size operations. Used internally by various Phaser systems for managing collections.

var map = new Map([
   [ 1, 'one' ],
   [ 2, 'two' ],
   [ 3, 'three' ]
]);
