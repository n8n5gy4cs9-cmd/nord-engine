uiPanel

A background box in the DOM UI layer.

UI type: "uiPanel"

For dummies

A rectangle on screen (HUD, menu background).

Notes

  • All ui* components share positioning: anchor (tl,tr,bl,br; edge-anchored), x, y, w, h, and screen (a named layer you show/hide with game.ui.show(name)).
