VRCameraMetrics #

export class VRCameraMetrics

Re-exports pure implementation and applies runtime side effects. Import vrDeviceOrientationArcRotateCamera.pure for tree-shakeable, side-effect-free usage.

This represents all the required metrics to create a VR camera. see (online reference)
