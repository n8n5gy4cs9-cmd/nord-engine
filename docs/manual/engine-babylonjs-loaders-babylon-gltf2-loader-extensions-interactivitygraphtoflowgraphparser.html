InteractivityGraphToFlowGraphParser #

export class InteractivityGraphToFlowGraphParser

Parses a KHR_interactivity graph definition (the raw glTF JSON object) into the serialized FlowGraph form consumed by ParseFlowGraphAsync.

The class walks the interactivity types, declarations, variables, events and nodes in order and emits an ISerializedFlowGraph via serializeToFlowGraph.

serializeToFlowGraph #

serializeToFlowGraph(): ISerializedFlowGraph;

Serializes the parsed interactivity graph into the ISerializedFlowGraph payload consumed by ParseFlowGraphAsync. Performs node-connection wiring and seeds the execution context with the graph's static variables. returns the serialized FlowGraph for the parsed KHR_interactivity graph.

Type / return: ISerializedFlowGraph
