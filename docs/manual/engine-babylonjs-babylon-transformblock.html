TransformBlock #

export class TransformBlock extends NodeMaterialBlock

Re-exports pure implementation and applies runtime side effects. Import triPlanarBlock.pure for tree-shakeable, side-effect-free usage.

This file must only contain pure code and pure imports Block used to transform a vector (2, 3 or 4) with a matrix. It will generate a Vector4
