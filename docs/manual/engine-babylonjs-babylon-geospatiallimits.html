pitchDisabledRadiusScale #

pitchDisabledRadiusScale?: Vector2;

Controls how pitch is disabled as the camera zooms out. x = radius scale at which full pitch is allowed (e.g., 1.5 means 1.5 * planetRadius) y = radius scale at which pitch is fully disabled (forced to pitchMin) Set to undefined to disable this feature.
