How To Use the Incremental Loading System#

To support incremental loading (introduced in v1.5.0), go to this page to get a tool that converts your .babylon file to a .incremental.babylon file alongside its associated resources (.babylonmeshdata and .babylongeometrydata files).

These files can be used just like a standard .babylon scene except that they will allow Babylon.js to load meshes and textures on the fly. This means that the meshes and the textures will not be loaded at startup but only when they become active (when the active camera can see them).

You have to put the .babylonmeshdata and .babylongeometrydata files in the same folder as the .incremental.babylon file.

You can find a demo of an incremental scene here: Online playground (not embedded offline)

Detailed Step-by-Step#

For users who are less experienced with command-line tools, here's a more detailed step-by-step guide to using the tool:

  1. Get the Exporters project (by either using git or downloading the ZIP):

    Upstream illustration: Exporters project (media not bundled).

  2. Download and install .NET Core 3.1

  3. Open a command prompt (cmd.exe should do the trick) and navigate to the MakeIncremental directory:

    Upstream illustration: MakeIncremental directory (media not bundled).

  4. Type dotnet build at the command prompt:

    Upstream illustration: .NET build (media not bundled).

  5. Navigate to the directory where the build files were written, \bin\Debug\netcoreapp3.1\:

    Upstream illustration: Build directory (media not bundled).

  6. Type the command MakeIncremental.exe /i:my-scene.babylon, where my-scene.babylon is the name of your scene (if your scene is named something else, just change what's after the : symbol):

    Upstream illustration: Run command (media not bundled).

  7. The script will generate quite a few files. You will need all of them except your original my-scene.babylon. Copy them to a directory your project can access (in this example, it's /src):

    Upstream illustration: Generated files (media not bundled).

  8. And you're ready to load it into Babylon!

await BABYLON.AppendSceneAsync("src/my-scene.incremental.babylon", scene);
console.log("My incremental file was loaded! WOHOO!");
