Flip #

interface Flip

Provides methods used for visually flipping a Game Object along its horizontal and/or vertical axes.

Flipping mirrors the rendered texture without altering the Game Object's scale, position, or physics body. The flip always pivots from the centre of the texture. This component is intended to be mixed in to Game Object classes and should not be used directly.

Public members (8)

Private, protected and explicitly internal declarations are excluded. Inherited members belong to the base type listed in the declaration.

flipX #

flipX: boolean;

The horizontally flipped state of the Game Object.

A Game Object that is flipped horizontally will render inverted on the horizontal axis. Flipping always takes place from the middle of the texture and does not impact the scale value. If this Game Object has a physics body, it will not change the body. This is a rendering toggle only.

Type / return: boolean

flipY #

flipY: boolean;

The vertically flipped state of the Game Object.

A Game Object that is flipped vertically will render inverted on the vertical axis (i.e. upside down). Flipping always takes place from the middle of the texture and does not impact the scale value. If this Game Object has a physics body, it will not change the body. This is a rendering toggle only.

Type / return: boolean
