FlowGraphMatrix3D #

export class FlowGraphMatrix3D implements IFlowGraphMatrix<Vector3>

A 3x3 matrix, stored in column-major order.

BREAKING: this class was row-major in earlier releases — see IFlowGraphMatrix for the full behaviour change (flat-array construction, transform, and multiply operand order).
