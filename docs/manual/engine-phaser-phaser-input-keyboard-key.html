Key #

class Key extends Phaser.Events.EventEmitter

Represents a single key on the keyboard. Key objects are created by the Keyboard Plugin via addKey() and track the state of a specific key, including whether it is currently held down, the duration it has been held, timestamps for press and release events, and repeat counts. You can poll Key objects directly in your game loop using properties like isDown and isUp, or listen for events via the on method. The keyCode must be an integer corresponding to a Phaser.Input.Keyboard.KeyCodes value.
