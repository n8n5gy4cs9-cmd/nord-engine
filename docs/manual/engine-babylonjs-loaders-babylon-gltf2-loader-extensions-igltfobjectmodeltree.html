IGLTFObjectModelTree #

export interface IGLTFObjectModelTree

Top-level shape of the glTF Object Model accessor tree. Each property describes a navigable section of the JSON-Pointer namespace (e.g. /nodes, /materials, /scenes) that KHR_interactivity, KHR_animation_pointer and other extensions consume via GetMappingForKey.
