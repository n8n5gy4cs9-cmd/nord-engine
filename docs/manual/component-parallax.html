Components

parallax

A screen-filling background layer that scrolls slower than the camera for depth.

2D type: "parallax"

For dummies

Far-away hills move slowly while nearby trees move fast — that is what makes it feel deep.

Fields

FieldTypeDefault
textureasset(image)—
factornumber0.5
fitbooltrue
scalenumber1

Field list comes from the editor's inspector schema. Types: see attribute types.

Notes

  • factor is [x, y] scroll speed relative to the camera (0 = fixed, 1 = moves with the world). Defaults: factor 0.5 (x), data key factor:[0.5,0].
  • fit scales the image to the screen height. Put several parallax entities at different layers.

In a scene

{
  "type": "parallax",
  "texture": "assets/sprites/backgrounds/hills.png",
  "factor": [
    0.3,
    0
  ]
}
