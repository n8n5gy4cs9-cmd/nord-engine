IGreasedLineMaterial #

export interface IGreasedLineMaterial

Re-exports pure implementation and applies runtime side effects. Import greasedLinePluginMaterial.pure for tree-shakeable, side-effect-free usage.

Interface which defines the available methods for a GreasedLineMaterial
