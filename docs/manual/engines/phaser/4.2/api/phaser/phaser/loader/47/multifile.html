MultiFile #

class MultiFile

A MultiFile is a composite file that groups two or more individual File objects as children and coordinates their loading and processing as a single unit. When all child files have loaded, the MultiFile's addToCache method is called to combine the results (e.g., associating a texture image with its JSON atlas data). It is commonly extended as a base class for file types such as AtlasJSON, BitmapFont, and AudioSprite. You should not create an instance directly, but extend it and override addToCache.
