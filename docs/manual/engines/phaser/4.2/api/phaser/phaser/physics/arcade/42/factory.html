Factory #

class Factory

The Arcade Physics Factory allows you to easily create Arcade Physics enabled Game Objects. Objects that are created by this Factory are automatically added to the physics world.

body #

body(x: number, y: number, width?: number, height?: number): Phaser.Physics.Arcade.Body;

Creates a new physics Body with the given position and size.

This Body is not associated with any Game Object, but still exists within the world and can be tested for collision, have velocity, etc. param x The horizontal position of this Body in the physics world. param y The vertical position of this Body in the physics world. param width The width of the Body in pixels. Cannot be negative or zero. Default 64. param height The height of the Body in pixels. Cannot be negative or zero. Default 64. returns The Body that was created.
