Phaser archive: Phaser.Tilemaps.MapData

Phaser 4.1.0 archive · Matching 4.2.1 API

A class for representing data about a map. Maps are parsed from CSV, Tiled, etc. into this format. A Tilemap object gets a copy of this data and then unpacks the needed properties into itself.
