Phaser archive: Phaser.Physics.Arcade.Factory

Phaser 4.1.0 archive · Matching 4.2.1 API

The Arcade Physics Factory allows you to easily create Arcade Physics enabled Game Objects. Objects that are created by this Factory are automatically added to the physics world.

Constructor

Factory(world)
ParameterTypeDetails
worldPhaser.Physics.Arcade.WorldThe Arcade Physics World instance.

members

scene

scene

A reference to the Scene this Arcade Physics instance belongs to.

sys

sys

A reference to the Scene.Systems this Arcade Physics instance belongs to.

world

world

A reference to the Arcade Physics World.

methods

body

body(x, y, width?, height?)

Creates a new physics Body with the given position and size.

This Body is not associated with any Game Object, but still exists within the world and can be tested for collision, have velocity, etc.

ParameterTypeDetails
xnumberThe horizontal position of this Body in the physics world.
ynumberThe vertical position of this Body in the physics world.
widthnumberOptional. The width of the Body in pixels. Cannot be negative or zero. Default: 64
heightnumberOptional. The height of the Body in pixels. Cannot be negative or zero. Default: 64

Returns: Phaser.Physics.Arcade.Body The Body that was created.

collider

collider(object1, object2, collideCallback?, processCallback?, callbackContext?)

Creates a new Arcade Physics Collider object.

ParameterTypeDetails
object1Phaser.Types.Physics.Arcade.ArcadeColliderTypeThe first object to check for collision.
object2Phaser.Types.Physics.Arcade.ArcadeColliderTypeThe second object to check for collision.
collideCallbackPhaser.Types.Physics.Arcade.ArcadePhysicsCallbackOptional. The callback to invoke when the two objects collide.
processCallbackPhaser.Types.Physics.Arcade.ArcadePhysicsCallbackOptional. An optional callback to invoke when the two objects are tested for collision. Return `true` to allow the collision to be processed, or `false` to prevent it.
callbackContext*Optional. The scope in which to call the callbacks.

Returns: Phaser.Physics.Arcade.Collider The Collider that was created.
