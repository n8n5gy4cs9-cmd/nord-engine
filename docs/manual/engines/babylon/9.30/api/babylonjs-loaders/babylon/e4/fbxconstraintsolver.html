FBXConstraintSolver #

export class FBXConstraintSolver

Solves every FBX constraint of a scene once per frame, in dependency order, from the scene's animation phase observers (beginFrame before animations, solve after them). Created on demand by the first FBXConstraintBehavior attached in the scene and removed with the last one.
