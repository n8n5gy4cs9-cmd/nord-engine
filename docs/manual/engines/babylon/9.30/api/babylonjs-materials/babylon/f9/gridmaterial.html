GridMaterial #

export class GridMaterial extends PushMaterial

The grid materials allows you to wrap any shape with a grid. Colors are customizable.

linesOnly #

get linesOnly(): boolean;

When true, only grid lines are visible — non-grid pixels are discarded. Puts the material in the alpha-blend queue and enables a depth pre-pass so grid lines correctly occlude translucent objects (e.g. Gaussian splats). Set mesh.alphaIndex to a value lower than other transparent objects so the depth pre-pass fires first.

Type / return: boolean
