ClusteredLightContainer #

export class ClusteredLightContainer extends Light

Re-exports pure implementation and applies runtime side effects. Import clusteredLightingSceneComponent.pure for tree-shakeable, side-effect-free usage.

This file must only contain pure code and pure imports A special light that renders all its associated spot or point lights using a clustered or forward+ system.
