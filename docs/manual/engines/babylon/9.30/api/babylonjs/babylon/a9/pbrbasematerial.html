PBRBaseMaterial #

export abstract class PBRBaseMaterial extends PBRBaseMaterialBase

The Physically based material base class of BJS.

This offers the main features of a standard PBR material. For more information, please refer to the documentation : (online reference) see [WebGL]((online reference)) see [WebGPU]((online reference))
