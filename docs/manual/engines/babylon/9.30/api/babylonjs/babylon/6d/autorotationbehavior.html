AutoRotationBehavior #

export class AutoRotationBehavior implements Behavior<ArcRotateCamera>

The autoRotation behavior (AutoRotationBehavior) is designed to create a smooth rotation of an ArcRotateCamera when there is no user interaction. see (online reference)
