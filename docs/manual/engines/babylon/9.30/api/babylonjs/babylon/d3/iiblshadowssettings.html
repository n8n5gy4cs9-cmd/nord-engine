IIblShadowsSettings #

interface IIblShadowsSettings

This file must only contain pure code and pure imports

Public members (14)

Private, protected and explicitly internal declarations are excluded. Inherited members belong to the base type listed in the declaration.

resolutionExp #

resolutionExp?: number;

The exponent of the resolution of the voxel shadow grid. Higher resolutions will result in sharper shadows but are more expensive to compute and require more memory. The resolution is calculated as 2 to the power of this number.

Type / return: number

sampleDirections #

sampleDirections?: number;

The number of different directions to sample during the voxel tracing pass. Higher values will result in better quality, more stable shadows but are more expensive to compute.

Type / return: number

shadowOpacity #

shadowOpacity?: number;

How dark the shadows are. 1.0 is full opacity, 0.0 is no shadows.

Type / return: number

envRotation #

envRotation?: number;

The global Y-axis rotation of the IBL for shadows. This should match the Y-rotation of the environment map applied to materials, skybox, etc.

Type / return: number

shadowRemanence #

shadowRemanence?: number;

A factor that controls how long the shadows remain in the scene. 0.0 is no persistence, 1.0 is full persistence. This value applies only while the camera is moving. Once stationary, the pipeline increases remanence automatically to help the shadows converge.

Type / return: number

triPlanarVoxelization #

triPlanarVoxelization?: boolean;

Render the voxel grid from 3 different axis. This will result in better quality shadows with fewer bits of missing geometry.

Type / return: boolean

shadowRenderSizeFactor #

shadowRenderSizeFactor?: number;

A size multiplier for the internal shadow render targets (default 1.0). A value of 1.0 represents full-resolution. Scaling this below 1.0 will result in blurry shadows and potentially more artifacts but could help increase performance on less powerful GPU's.

Type / return: number

voxelShadowOpacity #

voxelShadowOpacity?: number;

Separate control for the opacity of the voxel shadows.

Type / return: number

ssShadowsEnabled #

ssShadowsEnabled?: boolean;

Include screen-space shadows in the IBL shadow pipeline. This adds sharp shadows to small details but only applies close to a shadow-casting object.

Type / return: boolean

ssShadowSampleCount #

ssShadowSampleCount?: number;

The number of samples used in the screen space shadow pass.

Type / return: number

ssShadowStride #

ssShadowStride?: number;

The stride of the screen-space shadow pass. This controls the distance between samples in pixels.

Type / return: number

ssShadowDistanceScale #

ssShadowDistanceScale?: number;

A scale for the maximum distance a screen-space shadow can be cast in world-space. The maximum distance that screen-space shadows cast is derived from the voxel size and this value so shouldn't need to change if you scale your scene.

Type / return: number

ssShadowThicknessScale #

ssShadowThicknessScale?: number;

Screen-space shadow thickness scale. This value controls the assumed thickness of on-screen surfaces in world-space. It scales with the size of the shadow-casting region so shouldn't need to change if you scale your scene.

Type / return: number

maxVoxelRouletteTests #

maxVoxelRouletteTests?: number;

Maximum number of translucent voxels a shadow ray roulettes through before it is treated as unoccluded (default 16). Higher values converge more accurately through thick translucent volumes (e.g. dense Gaussian splats) at extra cost. Opaque voxels always block on first contact.

Type / return: number
