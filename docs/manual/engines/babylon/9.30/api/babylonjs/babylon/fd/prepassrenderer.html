PrePassRenderer #

export class PrePassRenderer

Re-exports pure implementation and applies runtime side effects. Import prePassRendererSceneComponent.pure for tree-shakeable, side-effect-free usage.

This file must only contain pure code and pure imports Renders a pre pass of the scene This means every mesh in the scene will be rendered to a render target texture And then this texture will be composited to the rendering canvas with post processes It is necessary for effects like subsurface scattering or deferred shading
