MultiRenderTarget #

export class MultiRenderTarget extends RenderTargetTexture

A multi render target, like a render target provides the ability to render to a texture. Unlike the render target, it can render to several draw buffers (render textures) in one draw. This is specially interesting in deferred rendering or for any effects requiring more than just one color from a single pass.
