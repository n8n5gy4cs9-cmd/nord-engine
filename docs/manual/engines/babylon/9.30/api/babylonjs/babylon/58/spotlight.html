SpotLight #

export class SpotLight extends ShadowLight

Re-exports pure implementation and applies runtime side effects. Import babylonFileLoader.pure for tree-shakeable, side-effect-free usage.

This file must only contain pure code and pure imports A spot light is defined by a position, a direction, an angle, and an exponent. These values define a cone of light starting from the position, emitting toward the direction. The angle, in radians, defines the size (field of illumination) of the spotlight's conical beam, and the exponent defines the speed of the decay of the light with distance (reach).
