instantiateModelsToScene #

instantiateModelsToScene(nameFunction?: (sourceName: string) => string, cloneMaterials?: boolean, options?: {
            doNotInstantiate?: boolean | ((node: Node) => boolean);
            predicate?: (entity: any) => boolean;
        }): InstantiatedEntries;

Instantiate or clone all meshes and add the new ones to the scene. Skeletons and animation groups will all be cloned param nameFunction defines an optional function used to get new names for clones param cloneMaterials defines an optional boolean that defines if materials must be cloned as well (false by default) param options defines an optional list of options to control how to instantiate / clone models param options.doNotInstantiate defines if the model must be instantiated or just cloned param options.predicate defines a predicate used to filter whih mesh to instantiate/clone returns a list of rootNodes, skeletons and animation groups that were duplicated
