LensFlareSystem #

export class LensFlareSystem

Re-exports pure implementation and applies runtime side effects. Import lensFlareSystemSceneComponent.pure for tree-shakeable, side-effect-free usage.

This represents a Lens Flare System or the shiny effect created by the light reflection on the camera lenses. It is usually composed of several lensFlare. see (online reference)
