FramingBehavior #

export class FramingBehavior implements Behavior<ArcRotateCamera>

The framing behavior (FramingBehavior) is designed to automatically position an ArcRotateCamera when its target is set to a mesh. It is also useful if you want to prevent the camera to go under a virtual horizontal plane. see (online reference)
