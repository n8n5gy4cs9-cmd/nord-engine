NodeRenderGraphIblShadowsRendererBlock #

export class NodeRenderGraphIblShadowsRendererBlock extends NodeRenderGraphBlock

Re-exports pure implementation and applies runtime side effects. Import objectRendererBlock.pure for tree-shakeable, side-effect-free usage.

This file must only contain pure code and pure imports Block that implements IBL (image-based lighting) shadows using voxel tracing.
