GaussianSplattingCompoundMesh #

export class GaussianSplattingCompoundMesh extends GaussianSplattingMesh

Re-exports pure implementation and applies runtime side effects. Import gaussianSplattingDebugger.pure for tree-shakeable, side-effect-free usage.

This file must only contain pure code and pure imports Class used to compose multiple Gaussian Splatting meshes into a single draw call, with per-part world-matrix and visibility control via addPart/addParts/removePart.

This is the recommended class for multi-part Gaussian Splatting use cases.

Next major version: the compound mesh API (addPart/addParts/removePart) will move exclusively to this class and will be removed from GaussianSplattingMesh.
