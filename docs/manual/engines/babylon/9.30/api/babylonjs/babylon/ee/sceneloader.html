SceneLoader #

export class SceneLoader

Class used to load scene from various file formats using registered plugins see (online reference) deprecated The module level functions are more efficient for bundler tree shaking and allow plugin options to be passed through. Future improvements to scene loading will primarily be in the module level functions. The SceneLoader class will remain available, but it will be beneficial to prefer the module level functions. see ImportMeshAsync, LoadSceneAsync, AppendSceneAsync, ImportAnimationsAsync, LoadAssetContainerAsync
