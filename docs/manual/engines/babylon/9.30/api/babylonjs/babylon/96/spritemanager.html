pixelPerfect #

get pixelPerfect(): boolean;

Gets or sets a boolean indicating if the renderer must render sprites with pixel perfect rendering In this mode, sprites are rendered as "pixel art", which means that they appear as pixelated but remain stable when moving or when rotated or scaled. Note that for this mode to work as expected, the sprite texture must use the BILINEAR sampling mode, not NEAREST!
