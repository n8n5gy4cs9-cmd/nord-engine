setBackBufferTextures(width: number, height: number, textureCreationOptions?: FrameGraphTextureCreationOptions, depthStencilTextureCreationOptions?: FrameGraphTextureCreationOptions): void;

Overrides the default back buffer color/depth-stencil textures used by the frame graph. Note that if both textureCreationOptions and depthStencilTextureCreationOptions are provided, the engine will use them to create the back buffer color and depth/stencil textures respectively.
