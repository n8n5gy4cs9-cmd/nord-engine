IWebXRTeleportationOptions #

export interface IWebXRTeleportationOptions

Re-exports pure implementation and applies runtime side effects. Import WebXRDOMOverlay.pure for tree-shakeable, side-effect-free usage.

This file must only contain pure code and pure imports The options container for the teleportation module
