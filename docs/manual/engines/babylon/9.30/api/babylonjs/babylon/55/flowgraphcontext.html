FlowGraphContext #

export class FlowGraphContext

The context represents the current state and execution of the flow graph. It contains both user-defined variables, which are derived from a more general variable definition, and execution variables that are set by the blocks.

breakpointPredicate #

breakpointPredicate: Nullable<(block: FlowGraphExecutionBlock) => boolean>;

A predicate called before each execution block runs. If it returns true, execution is paused before the block and a pending activation is stored, which can be resumed via continueExecution or stepExecution.

Set to null to disable breakpoint checking.
