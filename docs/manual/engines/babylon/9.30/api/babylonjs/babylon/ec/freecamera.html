FreeCamera #

export class FreeCamera extends TargetCamera

This file must only contain pure code and pure imports This represents a free type of camera. It can be useful in First Person Shooter game for instance. Please consider using the new UniversalCamera instead as it adds more functionality like the gamepad. see (online reference)
