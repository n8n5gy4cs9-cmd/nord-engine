skipOutOfRangeLighting #

accessor skipOutOfRangeLighting: boolean;

If set to true, point and spot lights skip their lighting computations for fragments beyond the light range, where they contribute nothing. Only lights with a finite range are affected. The extra per-fragment test costs time when most fragments are within range of most lights, so only enable it for sparse lighting measured on the target devices (default: false).

Type / return: boolean
