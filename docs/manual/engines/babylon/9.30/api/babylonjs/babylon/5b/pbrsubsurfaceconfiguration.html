DEFAULT_APPLY_ALBEDO_AFTERSUBSURFACE #

static DEFAULT_APPLY_ALBEDO_AFTERSUBSURFACE: boolean;

Default value used for applyAlbedoAfterSubSurface.

This property only exists for backward compatibility reasons. Set it to true if your rendering in 8.0+ is different from that in 7 when you use sub-surface properties (transmission, refraction, etc.). Default is false. Note however that the PBR calculation is wrong when this property is set to true, so only use it if you want to mimic the 7.0 behavior.

Type / return: boolean

thicknessTexture #

accessor thicknessTexture: Nullable<BaseTexture>;

Stores the average thickness of a mesh in a texture (The texture is holding the values linearly). The red (or green if useGltfStyleTextures=true) channel of the texture should contain the thickness remapped between 0 and 1. 0 would mean minimumThickness 1 would mean maximumThickness The other channels might be use as a mask to vary the different effects intensity.

indexOfRefraction #

accessor indexOfRefraction: number;

Index of refraction of the material base layer. (online reference)

This does not only impact refraction but also the Base F0 of Dielectric Materials.

From dielectric fresnel rules: F0 = square((iorT - iorI) / (iorT + iorI))

useMaskFromThicknessTexture #

accessor useMaskFromThicknessTexture: boolean;

Stores the intensity of the different subsurface effects in the thickness texture. Note that if refractionIntensityTexture and/or translucencyIntensityTexture is provided it takes precedence over thicknessTexture + useMaskFromThicknessTexture

  • the green (red if useGltfStyleTextures = true) channel is the refraction intensity.
  • the blue (alpha if useGltfStyleTextures = true) channel is the translucency intensity.

Type / return: boolean

useGltfStyleTextures #

accessor useGltfStyleTextures: boolean;

Use channels layout used by glTF:

  • thicknessTexture: the green (instead of red) channel is the thickness
  • thicknessTexture/refractionIntensityTexture: the red (instead of green) channel is the refraction intensity
  • thicknessTexture/translucencyIntensityTexture: the alpha (instead of blue) channel is the translucency intensity

Type / return: boolean
