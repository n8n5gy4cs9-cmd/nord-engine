AudioEngine #

export class AudioEngine implements IAudioEngine

Re-exports pure implementation and applies runtime side effects. Import audioSceneComponent.pure for tree-shakeable, side-effect-free usage.

This file must only contain pure code and pure imports This represents the default audio engine used in babylon. It is responsible to play, synchronize and analyse sounds throughout the application. see (online reference)
