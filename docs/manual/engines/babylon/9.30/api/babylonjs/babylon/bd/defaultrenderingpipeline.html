DefaultRenderingPipeline #

export class DefaultRenderingPipeline extends PostProcessRenderPipeline implements IDisposable, IAnimatable

This file must only contain pure code and pure imports The default rendering pipeline can be added to a scene to apply common post processing effects such as anti-aliasing or depth of field. See (online reference)
