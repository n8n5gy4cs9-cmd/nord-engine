FlowGraphBlockNames #

export enum FlowGraphBlockNames

Re-exports pure implementation and applies runtime side effects. Import flowGraphInteger.pure for tree-shakeable, side-effect-free usage.

Pure barrel — re-exports only side-effect-free modules Enum of all block names. Note - if you add a new block, you must add it here, and must add it in the block factory!
