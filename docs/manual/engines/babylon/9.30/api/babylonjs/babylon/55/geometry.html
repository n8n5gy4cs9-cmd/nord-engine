RandomId #

static RandomId(): string;

You should now use Tools.RandomId(), this method is still here for legacy reasons. Implementation from (online reference) Be aware Math.random() could cause collisions, but: "All but 6 of the 128 bits of the ID are randomly generated, which means that for any two ids, there's a 1 in 2^^122 (or 5.3x10^^36) chance they'll collide" returns a string containing a new GUID
