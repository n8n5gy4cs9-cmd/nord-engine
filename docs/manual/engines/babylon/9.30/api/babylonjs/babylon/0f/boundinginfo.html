isInFrustum #

isInFrustum(frustumPlanes: Array<DeepImmutable<Plane>>, strategy?: number): boolean;

Returns true if the bounding info is within the frustum defined by the passed array of planes. param frustumPlanes defines the frustum to test param strategy defines the strategy to use for the culling (default is BABYLON.AbstractMesh.CULLINGSTRATEGY_STANDARD) The different strategies available are:

  • BABYLON.AbstractMesh.CULLINGSTRATEGY_STANDARD most accurate but slower @see (online reference)
  • BABYLON.AbstractMesh.CULLINGSTRATEGY_BOUNDINGSPHERE_ONLY faster but less accurate @see (online reference)
  • BABYLON.AbstractMesh.CULLINGSTRATEGY_OPTIMISTIC_INCLUSION can be faster if always visible @see (online reference)
  • BABYLON.AbstractMesh.CULLINGSTRATEGY_OPTIMISTIC_INCLUSION_THEN_BSPHERE_ONLY can be faster if always visible @see (online reference) returns true if the bounding info is in the frustum planes
ParameterTypeRequired / default
