ChromaticAberrationPostProcess #

export class ChromaticAberrationPostProcess extends PostProcess

Re-exports pure implementation and applies runtime side effects. Import circleOfConfusionPostProcess.pure for tree-shakeable, side-effect-free usage.

This file must only contain pure code and pure imports The ChromaticAberrationPostProcess separates the rgb channels in an image to produce chromatic distortion around the edges of the screen
