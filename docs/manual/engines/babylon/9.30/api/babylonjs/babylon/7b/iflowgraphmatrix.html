IFlowGraphMatrix #

export interface IFlowGraphMatrix<VectorType>

Pure barrel — re-exports only side-effect-free modules Interface representing a generic flow graph matrix.

BREAKING (since the KHR_interactivity work): FlowGraphMatrix2D and FlowGraphMatrix3D now store their elements in column-major order, matching core Matrix and the glTF/KHR_interactivity convention. Previous releases stored them row-major. This changes the result of building a matrix from a flat array (fromArray/set), of transformVector/transformVectorToRef, and of multiply/multiplyToRef (which now computes this * other rather than other * this). There is no compile error — graphs that relied on the old ordering or operand order get silently different numbers, so any code constructing these from raw arrays should be re-checked.
