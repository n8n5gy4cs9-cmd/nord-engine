This file must only contain pure code and pure imports Standard rendering pipeline Default pipeline should be used going forward but the standard pipeline will be kept for backwards compatibility. see (online reference)

constructor #

constructor(name: string, scene: Scene, ratio: number, originalPostProcess?: Nullable<PostProcess>, cameras?: Camera[]);

Default pipeline should be used going forward but the standard pipeline will be kept for backwards compatibility. @constructor param name The rendering pipeline name param scene The scene linked to this pipeline param ratio The size of the postprocesses (0.5 means that your postprocess will have a width = canvas.width 0.5 and a height = canvas.height 0.5) param originalPostProcess the custom original color post-process. Must be "reusable". Can be null. param cameras The array of cameras that the rendering pipeline will be attached to
