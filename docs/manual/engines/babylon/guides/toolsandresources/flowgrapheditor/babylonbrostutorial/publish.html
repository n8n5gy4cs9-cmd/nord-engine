Babylon guide: Step 8 - Save And Publish

Official Babylon guide · source snapshot

Read this as an underlying-engine guide

The prose snapshot can describe newer features. Nord's API pages match 9.30.0. Start with 3D manual · mesh · model · camera for Nord scene files and scripts. Online playgrounds, videos and upstream images are not embedded in this offline edition.

Goal#

Turn the finished graph into something a scene can run by saving it to a snippet and loading it at runtime.

Save To The Snippet Server#

In the editor, save to the snippet server. You get an ID back; the final tutorial graph is #HUA46E. To preview it against the level, load scene P41T6E#2 in the editor's preview panel.

Upstream illustration: The complete Babylon Bros graph in the editor, ready to save to the snippet server (media not bundled).

Load It From A Scene#

In your scene code, parse the coordinator from the snippet and start it:

const coordinator = await BABYLON.ParseFlowGraphCoordinatorFromSnippetAsync("HUA46E", { scene });
coordinator.start();

Because the scene does nothing on its own, this single graph is what brings it to life - movement, jumping, coins, springs, enemies, and the win condition all come from the flow graph.
