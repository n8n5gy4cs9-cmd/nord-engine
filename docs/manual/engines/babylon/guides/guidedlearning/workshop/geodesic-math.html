Babylon guide: Geodesic and Goldberg Polyhedra Mathematics

Overview#

In this design, we restrict both polyhedra to ones built from an icosahedron base. A Geodesic polyhedron is built from a number of equilateral triangles. A Goldberg polyhedron is the dual of a Geodesic one, and vice versa. A dual of a polyhedron swaps faces for vertices and vertices for faces.

Upstream illustration: Dual (media not bundled).


Fig 1 Icosahedron and its Dual

The simplest class of Geodesic polyhedra splits each face of an icosahedron into equilateral triangles.

Upstream illustration: Geodesic (media not bundled).


Fig 2 Geodesic Polyhedron

Upstream illustration: Geodesic Sphere (media not bundled).


Fig 3 Geodesic Polyhedron mapped to Sphere

More complex classes are formed by rotating, with restrictions, the isometric grid formed by the equilateral triangles that split each face.

Geodesic Classes#

A regular icosahedron is formed from 20 primary equilateral triangles. Rather than rotating the underlying grid we demonstrate the classes by rotating a primary triangle on a fixed isometric grid.

Rotations are formed by applying two positive integers m and n. From a fixed point O (0, 0) on the isometric grid form a point A (m, n) which is m horizontal units from O and n units along the positive gradient line. The primary triangle is formed with a point B such that OAB is an equilateral triangle. The Geodesic polyhedron so formed will be noted as GD(m, n) and its dual, the Goldberg polyhedron, as GP(m, n).

Upstream illustration: primary 1 (media not bundled).


Fig 4 Creating a GD(5, 2) on Isometric Grid

Upstream illustration: primary 2 (media not bundled).


Fig 5 Primary Triangle Grid Rotation 5, 2

There are three classes of these polyhedra:

  • Class I GD(m, 0)
  • Class II GD(m, m)
  • Class III GD(m, n) m ≠ n

For Class III GD(m, n) and GD(n, m) are reflections of each other as are GP(m, n) and GP(n, m). We only consider Class III GD(m, n) where m > n.

Building the Geodesic Polyhedron#

There are two main steps to this:

  1. Grouping the vertices into three to form each face of the Geodesic polyhedron
  2. Positioning the vertices in 3D space

In order to achieve both of these, we need to understand transformations on an isometric grid and how to match three facet vertices across the edges of a primary triangle. Using Fig 7 as a basis, we can then label each GD(m, n) vertex in a primary triangle using an isometric coordinate system and then use 60<sup>o</sup> rotations of a primary triangle to match up vertices to form the triangular facets of an adjacent primary triangle.

Transformations on an Isomorphic Grid#

In terms of the net, all the GD(m, n) vertices lie on an isometric grid, and we will need to rotate them 60<sup>o</sup> about given points. To understand how this is achieved, we consider isometric vectors and their transformations.

The x axis is horizontal and the angle between the x axis and the y axis is 60<sup>o</sup>

Upstream illustration: axis (media not bundled).


Fig 8 Isometric Axis

The unit vector along the x axis is i⃗ and along the y axis is j⃗; the unit vector k⃗ = -i⃗ + j⃗, which lies along the third line of an isometric grid, is also useful.

Upstream illustration: unit vectors (media not bundled).


Fig 9 Unit Vectors

Consider the position vector xi⃗ + yj⃗ its length |xi⃗ + yj⃗| = √(x<sup>2</sup> + y<sup>2</sup> + xy);. This is the result of applying the cosine rule to the triangle in Fig 10

|xi⃗ + yj⃗| = √(x<sup>2</sup> + y<sup>2</sup> - 2xycos(120<sup>o</sup>)); and cos(120<sup>o</sup>) = -0.5

Upstream illustration: length (media not bundled).


Fig 10 Unit Vectors

Vector additions still hold xi⃗ + yj⃗ + ai⃗ + bj⃗ = (x + a)i⃗ + (y + b)j⃗

Luckily, our application needs only integer values for the vectors and only rotations by multiples of 60<sup>o</sup>.

Consider the rotation of the position vector xi⃗ + yj⃗ 60<sup>o</sup> about the origin O, where x and y are integers. The rotation about the origin can be R<sup>+</sup> (counter-clockwise purple to red) or R<sup>-</sup> (clockwise purple to blue) as in Fig 11

Upstream illustration: rotation (media not bundled).


Fig 11 Rotation about the origin

R<sup>+</sup>(xi⃗ + yj⃗) = yk⃗ + xj⃗ = y(-i⃗ + j⃗) + xj⃗
= -yi⃗ + (x + y)j⃗

R<sup>-</sup>(xi⃗ + yj⃗) = yi⃗ - xk⃗ = yi⃗ - x(-i⃗ + j⃗);
= (x + y)*⃗ - xj⃗

Where S<sup>+</sup> and S<sup>-</sup> are respectively counter-clockwise and clockwise rotations of xi⃗ + yj⃗ 60<sup>o</sup> about a point ai⃗ + bj⃗

S<sup>+</sup>(xi⃗ + yj⃗, ai⃗ + bj⃗)
= R<sup>+</sup>((xi⃗ + yj⃗) - (ai⃗ + bj⃗)) + ai⃗ + bj⃗
= R<sup>+</sup>((x - a)i⃗) + (y - b)j⃗) + ai⃗ + bj⃗
= -(y - b)i⃗ + ((x - a) + (y - b))j⃗ + ai⃗ + bj⃗
= (a + b - *y)i⃗ + (x + y - a)j⃗

S<sup>-</sup>(xi⃗ + yj⃗, ai⃗ + bj⃗)
= R<sup>-</sup>((xi⃗ + yj⃗) - (ai⃗ + bj⃗)) + ai⃗ + bj⃗
= R<sup>-</sup>((x - a)i⃗ + (y - b)j⃗) + ai⃗ + bj⃗
= (x - a + y - b)i⃗ - (x - a)j⃗ + ai⃗ + bj⃗
= (x + y - b)i⃗ + (a + b - x)j⃗

Upstream illustration: rotation center (media not bundled).


Fig 12 Symmetry Rotations 0 <sup>o</sup>, 120<sup>o</sup>, -120<sup>o</sup>

We also need to consider rotations 120<sup>o</sup> and -120<sup>o</sup> about the center of the triangle OAB.

Let P have position vector xi⃗ + yj⃗ which after a rotation of 120<sup>o</sup> maps to P<sub>1</sub> and after a rotation of -120<sup>o</sup> maps to P<sup>2</sup>

P<sub>1</sub> = mi⃗ + nj⃗ - yi⃗ + xk⃗
= mi⃗ + nj⃗ - yi⃗ - xi⃗ + xj⃗
= (m - x - y)i⃗ + (n + x)j*⃗

P<sup>2</sup> = -ni⃗ + (m + n)j⃗ - yk⃗ - xj⃗
= -ni⃗ + (m + n)j⃗ + yi⃗ - yj⃗ - xj⃗
= (y - n)i⃗ + (m + n - x - y)j⃗

Where R<sup>C+</sup> is a rotation of 120<sup>o</sup> and R<sup>C-</sup> is a rotation of -120<sup>o</sup> about the center of OAB

R<sup>C+</sup>(xi⃗ + yj⃗) = (m - x - y)i⃗ + (n + x)j*⃗
R<sup>C-</sup>(xi⃗ + yj⃗) = (y - n)i⃗ + (m + n - x - y)j*⃗

In Fig 16 we can see that there are three types of rotated minimum vertices, 0, 1, and 2, that produce facets that overlap the edge. Each of these points can be associated with two facet triangles, one that is up (light grey) and one down (dark grey).

For all facet vertices xi⃗ + yj⃗ of a primary triangle OAB of GD(m, n) let M<sup>max</sup>(y) be the point with maximum x value and M<sup>min</sup>(y) the point with minimum x value for row y.

Let P = x<sub>p</sub>i⃗ + y<sub>p</sub>j⃗ be the position vector of a rotated minimum xi⃗ + yj⃗ = M<sup>min</sup>(y).

When P = M<sup>max</sup>(y<sub>p</sub>) the up and down facets lie inside the primary triangle are thus ignored in creating overlapping facets.

For an up facet When P is of type 0 and 1 the facet (light grey) has vertices P, M<sup>max</sup>(y<sub>p</sub> - 1), P + i⃗ - j⃗

When P is of type 2 the facet (light grey) has vertices P, M<sup>max</sup>(y<sub>p</sub> - 1) - i⃗, M<sup>max</sup>(y<sub>p</sub> - 1)

For a down facet When P is of type 0 the facet (dark grey) has vertices P, M<sup>max</sup>(y<sub>p</sub>), M<sup>max</sup>(y<sub>p</sub> - 1)

When P is of type 1 the facet (dark grey) has vertices P, P - i⃗, M<sup>max</sup>(y<sub>p</sub> - 1)

When P is of type 2 the facet (dark grey) has vertices P, M<sup>max</sup>(y<sub>p</sub>), M<sup>max</sup>(y<sub>p</sub> - 1) - i⃗

This range of vertex triples forms all the overlapping facets.

Facet Isometric Coordinates#

For each facet vertex that lies within the primary triangle, we determine the isometric coordinates (x, y). When constructing the primary triangle for GD(m, n), O is (0, 0), A is (m, n), and B is (-n, m + n); these are the white vertices in Fig 21.

Fig 21 Internal Facet Vertices

The red vertices lie on the maximum equilateral triangle CDE, that can be drawn wholly inside OAB along grid lines. The bottom left red vertex lies on the intersection of the y axis and the line through A parallel to the x axis and so has iso-coordinates (0, n).

D = R<sup>C+</sup>(0, n) = (m - n, n) and

Any facet vertices lying on an edge of a primary triangle will have the same position as that on a matched edge.

When n = 0, there is no rotation and there are m - 1 shared positions along each edge between the vertices.

When n ≠ 0, let g be the HCF (highest common factor) of m and n. When n = 1 there are no shared positions along each edge between vertices. When n > 1 let m<sub>1</sub> and n<sub>1</sub> be such that m = gm<sub>1</sub> and n = gn<sub>1</sub> then the number of shared positions between the vertices along one edge is g - 1.

Along OA they occur at m<sub>1</sub>i⃗ + n<sub>1</sub>j*⃗, 2m<sub>1</sub>i⃗ + 2n<sub>1</sub>j*⃗, ......, (g - 1)m<sub>1</sub>i⃗ + (g - 1)n<sub>1</sub>j*⃗.

Along AB at R<sup>C+</sup>(m<sub>1</sub>i⃗ + n<sub>1</sub>j*⃗), R<sup>C+</sup>(2m<sub>1</sub>i⃗ + 2n<sub>1</sub>j*&#8407);, ......, R<sup>C+</sup>((g - 1)m<sub>1</sub>i⃗ + (g - 1)n<sub>1</sub>j*⃗).

Mapping Primary Triangle to Icosahedron Face#

Upstream illustration: Primary Map (media not bundled).


Fig 27 Primary Triangle Mapping to Icosahedron Face

Let OAB be an equilateral triangle with a Cartesian frame of reference with unit vectors u&#8407 and v&#8407 along the X and Y axes respectively, and i⃗ and j⃗ the usual iso-vectors. O<sub>1</sub>A<sub>1</sub>B<sub>1</sub> and the frame of reference X<sub>1</sub>Y<sub>1</sub> are formed by a rotation and scaling of OAB and XY in 3D space, with u<sub>1</sub>&#8407 and v<sub>1</sub>&#8407, and i<sub>1</sub>⃗ and j<sub>1</sub>⃗, as the corresponding Cartesian and iso vectors.

Let P be any point with cartesian position vector xu⃗ + yv⃗. Let d be the scaling of O<sub>1</sub>A<sub>1</sub>B<sub>1</sub> to OAB. The corresponding point P<sub>1</sub> to P will have position vector xdu⃗<sub>1</sub> + ydv⃗<sub>1</sub>.

In iso_vectors OA = mi⃗ + nj⃗ and OB = -ni⃗ + (m + n)j⃗ and so in Cartesian vectors

OA = (m + 0.5n)u⃗ + 0.5√3nv⃗ and

OB = (0.5(m + n) - n)u⃗ + 0.5√3(m + n)v⃗ = 0.5(m - n)u⃗ + 0.5√3(m + n)v⃗

(m + 0.5n)OB = (m + 0.5n)(0.5(m - n))u⃗ + 0.5√3(m + n)(m + 0.5n)*uv⃗

(0.5(m - n))OA = (m + 0.5)(0.5(m - n))u⃗ + 0.5√3n(0.5(m - n))v⃗

(m + 0.5n)OB - (0.5(m - n))OA = 0.5√3((m + n)(m + 0.5n) - n(0.5(m - n)))v⃗

(2m + n)OB - (m - n)OA = √3(m<sup>2</sup> + 0.5n<sup>2</sup> + mn + 0.5mn - 0.5mn + 0.5n<sup>2</sup>)v⃗

(2m + n)OB - (m - n)OA = √3(m<sup>2</sup> + n<sup>2</sup> + mn)v⃗

from which we can find v⃗ and then u⃗ in terms of OA and OB.

Since O<sub>1</sub>A<sub>1</sub> = mdi<sub>1</sub>⃗ + ndj<sub>1</sub>⃗ and
O<sub>1</sub>B<sub>1</sub> = -ndi<sub>1</sub>⃗ + (m + n)dj<sub>1</sub>⃗

we can use this method to find v<sub>1</sub>⃗ and then u<sub>1</sub>⃗ in terms of O<sub>1</sub>A<sub>1</sub> and O<sub>1</sub>B<sub>1</sub> so that we can determine P<sub>1</sub>.

For example when finding v<sub>1</sub>⃗ the coefficient of O<sub>1</sub>B<sub>1</sub> will be

<ins>        d(m + n)        </ins>
 

d<sup>2</sup>√3(m<sup>2</sup> + n<sup>2</sup> + mn)

=

<ins>        (m + n)        </ins>
 

d√3(m<sup>2</sup> + n<sup>2</sup> + mn)

We also note that m<sup>2</sup> + n<sup>2</sup> + mn = l<sup>2</sup>, where l is the length of OA.

Doing the calculations for v<sub>1</sub>⃗ and for u<sub>1</sub>⃗ the coefficients of O<sub>1</sub>A<sub>1</sub> and of O<sub>1</sub>B<sub>1</sub> all contain the common multiplier 1 / dl<sup>2</sup>.

Since xu⃗ + yv⃗ in OAB maps to xdu⃗<sub>1</sub> + ydv⃗<sub>1</sub> in O<sub>1</sub>A<sub>1</sub>O<sub>1</sub>B<sub>1</sub> and d / dl<sup>2</sup> = 1 / l<sup>2</sup> when it comes to coding we can calculate constant coefficients just once and rather than calculating u⃗ and v⃗ as unit vectors calculate them as vectors scaled by d, for example

v⃗ = ((2m + n)O<sub>1</sub>B<sub>1</sub> - (m - n)O<sub>1</sub>A<sub>1</sub>) / l<sup>2</sup>√3
