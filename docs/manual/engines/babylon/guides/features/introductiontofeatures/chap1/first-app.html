Official Babylon guide · source snapshot

The prose snapshot can describe newer features. Nord's API pages match 9.30.0. Start with 3D manual · mesh · model · camera for Nord scene files and scripts. Online playgrounds, videos and upstream images are not embedded in this offline edition.

A Web Application Template

You will have seen that the template needed for any code on the Playground is:

var createScene = function () {
  var scene = new BABYLON.Scene(engine);

  // Add a camera to the scene and attach it to the canvas
  // Add a lights to the scene

  //Your Code

  return scene;
};

By following this format in your own project, you can quickly drop it into your own HTML page using the following as a template.

      // Add your code here matching the playground format

      const scene = createScene(); //Call the createScene function

      // Register a render loop to repeatedly render the scene
      engine.runRenderLoop(function () {
        scene.render();
      });

      // Watch for browser/canvas resize events
      window.addEventListener("resize", function () {
        engine.resize();
      });
    </script>
  </body>
</html>

This line

<script src="https://cdn.babylonjs.com/loaders/babylonjs.loaders.min.js"></script>

allows you to import models into your scene.

allows you to use a touch screen.

      // Add your code here matching the playground format
      const createScene = function () {
        const scene = new BABYLON.Scene(engine);

        BABYLON.ImportMeshAsync("https://assets.babylonjs.com/meshes/box.babylon");

        const camera = new BABYLON.ArcRotateCamera("camera", -Math.PI / 2, Math.PI / 2.5, 15, new BABYLON.Vector3(0, 0, 0));
        camera.attachControl(canvas, true);
        const light = new BABYLON.HemisphericLight("light", new BABYLON.Vector3(1, 1, 0));

        return scene;
      };

      const scene = createScene(); //Call the createScene function

      // Register a render loop to repeatedly render the scene
      engine.runRenderLoop(function () {
        scene.render();
      });

      // Watch for browser/canvas resize events
      window.addEventListener("resize", function () {
        engine.resize();
      });
    </script>
  </body>
</html>
