UI & HUD

game.ui is a lightweight DOM overlay on top of the canvas — crisp text, accessible, CSS-themed. It works the same in 2D, 3D and plain HTML projects. Widgets live on named screens (layers). hud always exists and is visible; create others for menus and show them on demand.

For dummies

Imagine a sheet of see-through plastic laid over the game. You draw the score, buttons and menus on that sheet, and the game keeps running underneath.

start() {
  const ui = this.ui;
  this.scoreLabel = ui.label('Score: 0', { x: 16, y: 16, size: 24 });                    // top-left by default
  this.hp = ui.bar(1, { x: 16, y: 56, w: 180, color: '#bf616a' });
  ui.menu('pause', [
    { text: 'Resume', onClick: () => { ui.hide('pause'); this.game.resume(); } },
    { text: 'Restart', onClick: () => this.game.restart() },
  ], { x: 200, y: 120 });
}
update() { this.scoreLabel.set(`Score: ${this.score}`); this.hp.set(this.health / 100); }

Positioning options for every widget: x, y, anchor ('tl'|'tr'|'bl'|'br'), w, h, screen, style. Widgets: panel, label, button, image, bar, menu. Handles have el (the DOM node) and remove(); labels and bars add set().

UI as components#

uiPanel, uiLabel, uiImage, uiBar, uiButton put the same widgets into the scene file so the editor can lay them out. A uiButton with event: "start-game" emits that name on game.events when clicked.

Themes and skins#

Project-level: "ui": { "skin": "cyber", "theme": "tokyo-night" }. A skin picks fonts, a theme picks colours (--nord-* CSS variables). At runtime: ui.setTheme({ theme: 'dracula', skin: 'cyber' }) or tweak single variables with ui.theme({ accent: '#ebcb8b' }). The catalogue is in assets/themes/themes.json (editor and game share it). Fonts come from vendor/fonts — nothing is loaded from the internet.

Ready-made screens (library)#

ui-hud, ui-main-menu, ui-pause, ui-gameover, ui-settings, ui-level-select, ui-loading, ui-toasts, ui-damage-numbers, ui-inventory, ui-joystick. See the catalog.

Touch controls#

virtualJoystick(input, parent) (or the ui-joystick library script) drives your four direction actions and input.stick, so the same axis/vec code works on phones.

In-world UI#

  • 2D: text component or damage-number script.
  • 3D: game.gui.worldLabel(entity, 'text') follows an entity in screen space (Babylon GUI).

Apps#

For tool/app projects the library has an app kit (library/apps/_kit.js: layout, forms, lists, router, state) and eight sample apps — see Templates & examples.
