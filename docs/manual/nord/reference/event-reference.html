Event sheet reference

Every condition, action and expression an event sheet can use. This page is generated from the runtime registries, so it always matches the engine. How events work: Event sheets · Behaviors.

In a sheet each node is { "object": "Player", "id": "set-x", "params": { "x": "100" } }; behavior nodes add "behavior": "Platform". Parameters are expressions (text parameters need quotes) except names, comparisons and keys.
