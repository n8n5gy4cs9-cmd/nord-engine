Component index

For dummies

All built-in components. Use the contents list to find a topic. Code names are case-sensitive; component settings belong to the selected object in the Inspector. Start with Getting started if you have not opened a project yet.

Every built-in component, grouped by where it works. Click one for fields, notes and script access.

2D

  • spriteA single image (or one frame of a spritesheet) drawn at the entity position.
  • animatedSpriteA spritesheet with named animations. Animations are declared in the texture's `.meta.json` (`anims`).
  • textWorld-space text (Phaser Text). For HUD text prefer `uiLabel`.
  • tilemapA grid of tiles from a tileset image. Loads Tiled JSON (`.tmj`/`.json`) or Nord simple maps (`layers[].data`).
  • parallaxA screen-filling background layer that scrolls slower than the camera for depth.
  • spriteMaskShows or hides sprites inside its shape (Unity's SpriteMask).
  • spriteShapeA filled shape with an edge line from a list of points (Unity's SpriteShape: hills, platforms, pools).

3D

  • meshA primitive 3D shape (box, sphere, cylinder, capsule, torus, plane, ground).
  • modelA glTF/GLB model instanced into the scene, with its animations.
  • materialPBR (or unlit) material applied to the meshes of this entity.
  • skyboxCube-map sky. `path` is a folder containing px/nx/py/ny/pz/nz.png (e.g. `assets/skybox/day`).
  • postProcessFull-screen effects on the active camera: bloom, FXAA/MSAA, vignette, tone mapping, grain, sharpen, chromatic aberration.

2D + 3D

  • particlesParticle emitter. 2D (Phaser emitter) and 3D (Babylon ParticleSystem) use the same component with tier-specific fields.
  • camera2D: configures the main camera (zoom, follow, bounds). 3D: creates a free (first-person) or orbit camera.
  • light2D: Phaser point light (turns on the light pipeline for all sprites). 3D: point / directional / spot / hemispheric light, optional shadows.
  • rigidbodyMakes the entity a physics body. Add a `collider` for its shape.
  • colliderCollision shape. Without an explicit `size` it is taken from the sprite/mesh bounds.
  • jointA Unity-style joint between this body and `connectedBody` (or the world): hinge, spring, distance, fixed, slider, wheel, target, relative, friction (2D, Matter) and hinge, fixed, spring, distance, ball (CharacterJoint), configurable (3D, Havok).
  • triggerShorthand for a collider with `trigger: true` — an invisible zone that fires `onTriggerEnter` / `onTriggerExit`.
  • lineRendererA poly-line drawn as a ribbon with a width and a colour gradient (Unity's LineRenderer).
  • trailRendererLeaves a fading trail behind a moving entity (Unity's TrailRenderer).
  • shadertoyRuns a shader written for shadertoy.com (GLSL ES 3.00 `mainImage`) as a picture in the scene or on a mesh.
  • audioSourcePlays a clip from an entity. Use `bus` to route it (sfx | music | ui).
  • audioListenerMarker for the entity that "hears" the game. Currently a no-op placeholder (audio is not spatialised yet).
  • pathA list of waypoints that can be sampled by distance — for patrols, moving platforms, camera rails.
  • spawnerSpawns a prefab every `interval` seconds at the entity (plus `offset` and random `jitter`), keeping at most `max` alive.
  • graphRuns a visual-scripting graph file (`graphs/*.graph.json`) on this entity. *This entity* in the graph is the owner. Built in the Graph tab.
  • animatorUnity-style state machine (`anim/*.animator.json`) that switches the clip of the `animatedSprite` (or the glTF animation of the `model`) on the same entity from parameters (float, int, bool, trigger). Built in the Animator tab; see the Animator chapter.
  • netSyncMultiplayer: the owning peer sends this entity's position (and optionally rotation, scale and chosen `vars`) to everyone else, who see it move smoothly. Owner = the player given to `net.spawn`, otherwise the host. Needs `game.net` connected; see the Multiplayer chapter.

UI

  • uiPanelA background box in the DOM UI layer.
  • uiLabelText in the DOM UI layer.
  • uiImageAn image in the DOM UI layer.
  • uiBarA progress bar (0..1).
  • uiButtonA clickable button. Emits `click` on the entity, calls `onClick()` on its scripts and, if `event` is set, `game.events.emit(event)`.
