Phaser & Babylon documentation

Nord wraps existing engines. This library documents their public APIs when you need to work with an underlying engine object.

Begin with Nord

Build with Nord components and game services. The underlying engine API is an advanced reference, not a second setup guide.

  • Phaser 4.2.1 APIAll public declarations, members, signatures, types and JSDoc from Nord's exact version.
  • Babylon 9.30.0 APICore, loaders, GUI, materials, post-process, procedural textures and serializers.
  • Official Babylon guides816 cloned prose guides. Online media omitted; prose can describe newer features.
  • Supplied Phaser documentation4.1.0 archive retained and labelled separately from the matching reference.
