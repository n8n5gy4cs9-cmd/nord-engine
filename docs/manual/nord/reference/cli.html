Command line (nord)

The nord command-line tool (crates/nord-cli). Run nord --help or nord <command> --help for the same text.

nord info

Print engine info

nord new

Create a new project from a template

ArgumentTypeDefault
<dir>PathBuf—Directory to create (its name becomes the project name)
-t, --templateStringhtmlhtml | 2d | 3d | wasm-game | wasm-app, or a starter id from templates/ (e.g. platformer, fps-arena)

nord doctor

Check the toolchain and recommend a project tier

nord thumbs

Generate thumbnails for all project assets into .nord-cache/thumbs

ArgumentTypeDefault
<project>PathBuf.

nord check

Validate project + scenes (ids, missing files)

ArgumentTypeDefault
<project>PathBuf.

nord serve

Dev server with live reload and /api/* editor backend

ArgumentTypeDefault
<project>PathBuf.
-p, --portu164173

nord build

Build a static, offline web export (web-2d / web-3d / web-3d-pc / html / web-wasm-game / web-wasm-app) into a folder

ArgumentTypeDefault
<project>PathBuf.
-t, --targetStringautoauto | html | web-2d | web-3d | web-3d-pc | web-wasm-game | web-wasm-app
-o, --outOption<PathBuf>—Output folder (default: <project>/dist)
--minifybool—Minify JS and JSON
--single-filebool—One index.html with everything inlined (works from file://)
--optimizebool—Lossless PNG recompression, WAV→MP3 when ffmpeg is installed
--zipbool—Also write <out>.zip (for itch.io style uploads)

nord build-rust

Build a Rust (wasm-game / wasm-app) project for `nord serve`: cargo build → target/web/

ArgumentTypeDefault
<project>PathBuf.
--releasebool—optimised build (slower, smaller)

nord bundle-mac

Wrap a web build (or a project, built first) into a macOS .app using the prebuilt nord-player shell

ArgumentTypeDefault
<input>PathBuf.A web build folder (nord build output) or a project folder
--nameOption<String>—
-o, --outPathBuf.Output folder for the .app (default: current directory)
--playerOption<PathBuf>—nord-player binary or NordPlayer.app (default: auto-detect)
--iconOption<PathBuf>—PNG for the app icon
--dmgbool—Also create a .dmg (macOS only)

nord bundle-portable

Wrap a web build (or project) into a Windows / Linux desktop bundle (folder + zip / tar.gz) with the prebuilt nord-player

ArgumentTypeDefault
<input>PathBuf.
--osString—windows | linux
--nameOption<String>—
-o, --outPathBuf.
--playerOption<PathBuf>—nord-player binary for the target OS (default: auto-detect)
--iconOption<PathBuf>—
--no-archivebool—Skip the .zip / .tar.gz

nord check-offline

Fail if a directory (build output or project) references external http(s) hosts

ArgumentTypeDefault
<dir>PathBuf.
--allowVec<String>—Extra allowed host (repeatable); `.offline-allow` in the dir is also read

nord vendor

Vendored library tools

ArgumentTypeDefault
--verifybool—Verify sha256 of vendored files against vendor/VENDOR.json
