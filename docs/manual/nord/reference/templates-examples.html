Templates & examples

Start a project from a template with nord new my-game -t <id> (or the project hub). Examples are complete games in examples/ — open them in the editor to see how they are built.

Starter templates

  • Two Floors — Dungeon Creatordungeon-two-floors · 2d — Editable two-floor Shattered Pixel Dungeon adaptation: turns, bump combat, fog, keys, doors and relic. GPL-3.0-or-later.
  • Tiny Tank Patrol — NES-style Arenatank-patrol · 2d — Editable top-down tank action: destructible cover, shells, enemies and base defense.
  • 2D Platform Workshoplevel2d-platform · 2d — 2D Level Creator side-scroller with Amiga sprite bank and Arcade physics.
  • 2D Top-down Workshoplevel2d-topdown · 2d — 2D Level Creator top-down map, sprite bank, pickups and collision.
  • Machine Workshopmachine-workshop · 2d — 2D Matter physics puzzle: ball, ramps, basket, editable mass, bounce and friction.
  • Desktop app: clipboard managerdesktop-clipboard-manager · html — Clipboard history with search/pin, tray icon + menu, global shortcut Ctrl+Alt+V, badge count.
  • Desktop app: code editordesktop-code-editor · html — Tabs, file tree, syntax highlighting (JS/TS/HTML/CSS/JSON/MD/Rust/GLSL/TOML), find & replace, multi-cursor, quick open — CodeMirror 6 + window.nord.desktop.
  • Desktop app: notesdesktop-notes · html — Notes as files in the app data folder: search, reorder, autosave, import/export dialogs, reminders (notifications), dark-mode follow, en/de.
  • Desktop app: file organiserdesktop-file-organizer · html — Pick a folder, sort files into folders by type/month with preview + undo, find duplicates (SHA-256), virtual table for 10k+ files.
  • Desktop app: markdown editordesktop-markdown-editor · html — Split view CodeMirror + live sanitised preview (marked), open/save/export HTML, drag-drop, file association for .md.
  • UI app (Todo)ui-app · html — Plain HTML/JS app with a tiny DOM kit — todo list with persistence. Swap in any library app kit.
  • Desktop app: local web serverdesktop-web-server · html — Serve a folder over HTTP: live reload, SPA fallback, CORS, directory listing, request log + graph — window.nord.desktop.server.
  • Endless one-button (Flappy)endless-runner · 2d — Scrolling obstacles, one-button control, score and restart.
  • FPS arenafps-arena · 3d — First-person controller (mouse look, sprint, crouch, jump), hit-scan weapon, destructible targets.
  • FPS Creator (level editor)fps-creator · 3d — Build first-person shooter levels like FPS Creator: grid editor with walls, doors, windows, stairs, lights, ready-made enemies, pickups and scripts — plus a playable demo level.
  • Idle / clickeridle-clicker · 2d — Currency, upgrades with cost scaling, per-second income, offline progress, autosave.
  • Puzzle (Match-3)puzzle-match3 · 2d — Swap-and-match core: board, cascades, refill, score and move limit.
  • Card game (Memory)card-game · 2d — Card grid with flip animation, matching logic, move counter and win state — DOM UI based.
  • Platformerplatformer · 2d — Tilemap level, hero with coyote time/variable jump/dash, enemies you can stomp, coins, checkpoints, boss, HUD.
  • 3D platformerplatformer-3d · 3d — Third-person-ish 3D platformer: coyote jump, double jump, moving platform, gems, respawn.
  • Racing (time-trial)racing · 3d — Arcade car, checkpoints, lap timer, best lap saved, chase camera.
  • Endless runnerrunner · 2d — Auto-running character with jump/duck, obstacles, speed ramp and distance score.
  • Grid game (Snake)puzzle-grid · 2d — Tile-based game loop: timed steps, grid entities, food, game over.
  • Shooter (Space)shooter · 2d — Side-scrolling shooter: player ship, bullets, waves of enemies, score and game over.
  • Top-down adventuretopdown-adventure · 2d — Rooms, NPC dialogue, inventory, key + door, pickups, chasing enemies, HUD.
  • Tower defensetower-defense · 2d — Path, waves of creeps, click-to-build towers with range and fire rate, gold and lives.
  • Visual novelvisual-novel · 2d — Branching dialogue from a JSON file (library dialogue script): speakers, typewriter text, choices.
  • Rust 2D gamerust-2d-game · wasm-game — macroquad + rapier2d runtime, scenes in JSON, scripts in Rust (builds to WebAssembly).
  • Rust egui apprust-egui-app · wasm-app — eframe/egui app that runs natively and in the browser (wasm-bindgen, no trunk).
  • Rust Bevy game (optional)rust-bevy-game · wasm-app — Slim Bevy 0.16 app (WebGL2): spinning cube starter. Runs natively and in the browser via the wasm-app export path; own ECS, no Nord scenes.
  • Platformer (event sheet)es-platformer · 2d — Platform behavior, coins, slimes, a turret and a goal — everything is an event sheet. The tutorial T24 game.
  • Top-down shooter (event sheet)es-topdown-shooter · 2d — WASD + mouse aim, bullets, chasing enemies, score and lives — no scripts, all event sheet + behaviors.
  • Endless runner (event sheet)es-endless-runner · 2d — Auto-run, jump over obstacles, speed ramp, distance score — event sheet + Platform/Bullet behaviors only.
  • Lights Out puzzle (event sheet)es-lights-out · 2d — Grid puzzle with instance variables, picking by expression and a solvable shuffle — pure event sheet.
  • Menu starter (event sheet)es-menu-starter · 2d — Main menu, options (language + volume) and a game scene, wired with game events and string tables (English/Finnish).
  • Multiplayer squares (event sheet)es-multiplayer · 2d — Two-player WebRTC demo: host/join in the same room over the local network (needs `nord serve`), positions synced with Send/On message.
