shadertoy

Runs a shader written for shadertoy.com (GLSL ES 3.00 `mainImage`) as a picture in the scene or on a mesh.

2D + 3D type: "shadertoy"

For dummies

Paste a Shadertoy shader and see it animate inside your game.

Field list comes from the editor's inspector schema. Types: see attribute types.

Notes

  • file is a .glsl asset (or code holds the text). Inputs iResolution, iTime, iMouse, iFrame, iDate, iChannel0..3, Buffer A–D and a Common tab work like on Shadertoy; see the Shadertoy page in Examples for channels (texture, buffer, keyboard, audio, cubemap, screen).
  • 2D: the picture is size world units big (fullscreen: true fixes it to the camera, layer sets the depth). 3D: a plane of size units (target: material puts it on this entity's own mesh). resolutionScale renders at a fraction of the size for speed.
  • Scene post effect: game.effects.add('scene', 'shadertoy', { file, channels: [{ type: 'screen' }] }).

In a scene

In the Inspector, use + Add component and choose this component. Set its fields above; the selected object now has this behavior.

In the file scenes/main.scene.json (one entry in the selected entity’s components array):

{
  "type": "shadertoy",
  "file": "assets/shaders/plasma.glsl",
  "size": [
    320,
    180
  ],
  "resolutionScale": 0.75
}

From a script

Get the runtime component with this.entity.getComponent('shadertoy').

Live-settable with entity.set('shadertoy', key, value): speed, paused, uniforms. Other keys are just stored.

const st = this.entity.getComponent('shadertoy');
await st.ready;
st.st.setUniform('uSpeed', 2.0);   // a `uniform float uSpeed;` the shader declares
