audioSource

Plays a clip from an entity. Use `bus` to route it (sfx | music | ui).

2D + 3D type: "audioSource"

For dummies

A speaker attached to an object.

Fields

FieldTypeDefault
clipasset(audio)—
volumenumber1
loopbool—
autoplaybool—
busenum(sfx|music|ui)sfx

Field list comes from the editor's inspector schema. Types: see attribute types.

In a scene

{
  "type": "audioSource",
  "clip": "assets/audio/sfx/coin.wav",
  "autoplay": false
}

From a script

Get the runtime component with this.entity.getComponent('audioSource').

  • play(options) — restarts the clip, returns the audio handle
  • stop()
this.entity.getComponent('audioSource').play({ volume: 0.5 });
