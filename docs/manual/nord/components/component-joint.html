joint

A Unity-style joint between this body and `connectedBody` (or the world): hinge, spring, distance, fixed, slider, wheel, target, relative, friction (2D, Matter) and hinge, fixed, spring, distance, ball (CharacterJoint), configurable (3D, Havok).

2D + 3D type: "joint"

For dummies

A hinge on a door, a rope, a spring: two bodies that stay tied together in a chosen way.

Notes

  • connectedBody is another entity (empty = joined to the world). anchor is a point in this entity's own space, connectedAnchor in the other body's; with autoConfigureConnectedAnchor the second anchor is placed so the joint starts relaxed.
  • collideConnected: false (default) lets the two bodies overlap. breakForce > 0 breaks the joint and calls onJointBreak on the scripts (2D).
  • hinge: useLimits + lowerAngle / upperAngle, useMotor + motorSpeed (degrees/s) + maxMotorTorque. spring / distance: distance, autoConfigureDistance, frequency, dampingRatio. slider / wheel: angle, translation limits. target: pulls the anchor to target. 3D axis is the hinge axis in this entity's space.
  • Script access: entity.AddComponent(HingeJoint2D), GetComponent(SpringJoint2D) … see the Unity API reference.

In a scene

In the Inspector, use + Add component and choose this component. Set its fields above; the selected object now has this behavior.

In the file scenes/main.scene.json (one entry in the selected entity’s components array):

{
  "type": "joint",
  "kind": "hinge",
  "connectedBody": "anchor-id",
  "anchor": [
    0,
    -40,
    0
  ],
  "useMotor": true,
  "motorSpeed": 90
}

From a script

Get the runtime component with this.entity.getComponent('joint').

Live-settable with entity.set('joint', key, value): useMotor, motorSpeed, useLimits, lowerAngle, upperAngle, breakForce, target, (other fields rebuild the joint). Other keys are just stored.
