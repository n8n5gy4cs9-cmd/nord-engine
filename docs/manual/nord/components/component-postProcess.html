postProcess

Full-screen effects on the active camera: bloom, FXAA/MSAA, vignette, tone mapping, grain, sharpen, chromatic aberration.

3D type: "postProcess"

For dummies

Instagram filters for your game: glow, dark corners, film grain.

Fields

FieldTypeDefault
bloombool—
bloomThresholdnumber0.8
bloomWeightnumber0.3
fxaabool—
vignettenumber—

Field list comes from the editor's inspector schema. Types: see attribute types.

Notes

  • Created on the first frame after a camera exists. exposure/contrast tweak the final image. Changing a field at runtime re-applies the pipeline.

In a scene

In the Inspector, use + Add component and choose this component. Set its fields above; the selected object now has this behavior.

In the file scenes/main.scene.json (one entry in the selected entity’s components array):

{
  "type": "postProcess",
  "bloom": true,
  "vignette": 0.4,
  "tonemap": true
}

From a script

Get the runtime component with this.entity.getComponent('postProcess').

Live-settable with entity.set('postProcess', key, value): (any field). Other keys are just stored.
