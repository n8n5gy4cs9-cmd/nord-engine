material

PBR (or unlit) material applied to the meshes of this entity.

3D type: "material"

For dummies

The paint and finish of a 3D object: colour, shininess, a texture on top.

Fields

FieldTypeDefault
assetasset(material)—
colorcolor—
metallicnumber—
roughnessnumber0.8
textureasset(image)—
normalMapasset(image)—

emissiveMapasset(image)—

Field list comes from the editor's inspector schema. Types: see attribute types.

Notes

  • metallic/roughness 0..1. texture = albedo, normalMap for bumps, emissive glows. unlit skips lighting (flat colour). Optional uvScale [u,v] to tile textures.

In a scene

{
  "type": "material",
  "color": "#ff8844",
  "roughness": 0.5
}

From a script

Get the runtime component with this.entity.getComponent('material').

Live-settable with entity.set('material', key, value): color, metallic, roughness, alpha, emissive. Other keys are just stored.

this.entity.set('material', 'color', '#ff0000');
