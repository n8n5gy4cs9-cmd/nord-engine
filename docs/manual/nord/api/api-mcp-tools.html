MCP tools reference

This page lists the 50 tools your AI agent can call. A star (*) marks a required parameter. How to install, enable and disable the servers: AI and MCP. Full text of each tool description: docs/MCP.md.

For dummy developers

A tool is one thing the AI is allowed to do, like "add an object to the scene" or "draw a rectangle on a sprite". The AI picks tools itself while it works. You never call them by hand; you just tell the AI what you want.

Project, scenes and building#

Tool What it does Parameters
nord_guide READ THIS FIRST. topic, offset
project_open Point the tools at a Nord project folder (it must contain nord.project.json). path*
project_new Create a new project with the nord CLI from a template (html, 2d, 3d, or a starter id like platformer, endless-runner, fps-arena, card-game — see templates/) and open it. dir*, template
project_templates List the starter templates available for project_new. none
project_info Summary of the open project: manifest, scenes, scripts, prefabs, models, asset counts. none
library_list Search the engine's ready-made library (scripts, prefabs, shaders, snippets): AI, camera, UI, inventory, dialogue, a Dev Console prefab and more. query, limit
library_add Copy a library item into the open project: scripts go to scripts/, prefabs to prefabs/ (with the scripts they need). id*
list_files List files in a project folder (recursive, max 300). dir, pattern
read_file Read a text file of the project (max 200 KB; use offset for more). path*, offset
write_file Create/overwrite a project file (scripts, scenes, prefabs, json, css…). path, content, encoding
component_schema Fields of the scene component types (sprite, model, camera, light, rigidbody, collider, audioSource, uiButton, spawner, netSync, …) taken from the editor's schema. kind
scene_create Create an empty scene file (format 1). path*
project_set_start_scene Set the scene the game starts with. scene*
scene_get Show a scene as a compact outline (entity id, name, components, scripts, children) or one entity as full JSON (id given). scene, id
scene_add_entity Add an entity to a scene. scene, name*, pos, rot, scale, components, scripts, tags, layer, parent, prefab
scene_update_entity Change an entity: name, enabled, tags, layer, pos/rot/scale, set_components (add or replace by type), remove_components (types), scripts (replaces the list). scene, id*, name, enabled, tags, layer, pos, rot, scale, set_components, remove_components, scripts
scene_remove_entity Remove an entity (and its children) from a scene. scene, id*
check_project Validate the project and all scenes (ids, missing files, bad references) with nord check. none
build_project Build a static offline web export with nord build (target auto | html | web-2d | web-3d …). target, out, single_file, minify, zip, pwa, host
serve_start Start the dev server (live reload, editor API) for the open project in the background. port
serve_stop Stop the dev server started by serve_start. none
unity_scan Read-only inventory of a Unity project folder (the one with Assets/ and ProjectSettings/): Unity version, packages, scenes in build order, prefabs, every C# script with classes/base types/serialized fields/lifecycle/Unity APIs used, assets by type, tags, layers, input axes, physics gravity. path*
unity_cs_outline Outline of one C# file (or pasted C# source): classes, base types, [SerializeField]/public fields with defaults, lifecycle methods, coroutines and which Unity systems it touches. path, source
unity_scene_to_nord Convert a Unity .unity scene or .prefab (text YAML) into a Nord scene/prefab skeleton: GameObjects become entities with the hierarchy, position/rotation/scale, tag, layer, active flag, sprite/camera/collider/rigidbody components, and scripts whose GUID resolves to a .cs file become script references with the serialized values. unityProject, file, pixelsPerUnit, out

3D Modeler#

Tool What it does Parameters
modeler_list List models in the project's models/ folder and the open modeler sessions. none
modeler_new Start an empty model session. name*, color
modeler_open Open an existing model for editing: models/x.mesh.json (editable mesh) or any .glb/.gltf of the project (e.g. file*, name
modeler_describe Describe a model: counts, bounds, and a face table (index, direction, centre, vertex count) so you can address faces by index or direction. name*, limit
modeler_primitive Add a primitive (cube, plane, cylinder, sphere) with UVs. name, kind, size, position, rotation, segments
modeler_add_mesh Add raw geometry: vertices [[x,y,z]…] and faces as arrays of vertex indices (3+ per face, counter-clockwise seen from outside, planar). name, vertices, faces*, uvs
modeler_transform Move / rotate / scale vertices of the selected faces (or all). name, op, value*, faces, vertices, pivot
modeler_extrude Extrude faces along their normals by distance (negative = inward), adding side walls. name, faces, distance*, inset
modeler_delete_faces Delete faces (unused vertices are removed). name, faces
modeler_mirror Duplicate the model mirrored across the origin plane (x, y or z) and weld the seam. name, axis
modeler_center_ground Centre the model on x/z and put its lowest point on y = 0. name*
modeler_unwrap Recompute UVs: every face is projected along its dominant axis and all faces are packed into a grid on the texture. name*
modeler_set_color Colours: base colour of the whole model, or vertex colours of selected faces (multiplies with base colour and texture). name, color, faces
modeler_texture_new Create (or reset) the texture: size×size pixels filled with a colour. name*, size, color
modeler_texture_uv Where faces sit on the texture, in the same normalised coordinates modeler_texture_paint uses (x right, y DOWN, 0..1). name*, faces
modeler_texture_paint Paint on the texture. name, ops
modeler_preview Render the model with a built-in software renderer and return PNG image(s). name*, views, yaw, pitch, size, zoom
modeler_save Write models/.mesh.json (editable) and, by default, models/.glb (use it in a scene: model component path "models/.glb"). name*, as, glb

2D Sprite editor#

Tool What it does Parameters
sprite_new Create a new PNG sprite (default fully transparent). path, width, height*, color
sprite_list List the PNG files of the project (assets/ and everywhere else) with their sizes. dir
sprite_describe Describe a sprite: size, number of colours, the most used colours (palette letters) and, for images up to 64x64, the pixel grid as text (. path*
sprite_draw Draw on a PNG with the editor's tools. path, ops
sprite_from_ascii Paint pixel art from text: rows is an array of strings, one character per pixel, palette maps a character to a colour ("." and " " are transparent unless listed). path, rows, palette*, x, y
sprite_transform Whole-image edits: flip_h, flip_v, rotate_cw, rotate_ccw, crop (box x,y..x1,y1 inclusive; outside = transparent, so it can also grow the canvas), scale (integer factor, nearest neighbour: keeps pixels sharp), stamp (paste another PNG "source" at x,y; transparent pixels are skipped). path, op, x, y, x1, y1, factor, source
sprite_meta Import settings of a texture (written next to it as .meta.json, read by the engine and the editor): frameWidth/frameHeight (cut a sprite sheet into frames, used by animatedSprite), filter ("nearest" keeps pixel art sharp, "linear" smooths), ppu (pixels per world unit in 3D), wrap ("clamp"|"repeat"). path*, frameWidth, frameHeight, filter, ppu, wrap
sprite_preview Render the sprite as an enlarged PNG (nearest neighbour, checkerboard behind transparent pixels) so you can look at it. path*, scale, grid
Tip

Tools that change files (scene_*, write_file, sprite_*, modeler_save) write straight to your project folder. If the Nord editor has the scene open, it notices the change within a second and reloads it (or asks, when you have unsaved edits).
