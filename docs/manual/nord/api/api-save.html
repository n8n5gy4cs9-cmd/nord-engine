Versioned save slots (this.save). An API entry is a contract: check its owner, inputs, return value and supported backend. A JavaScript helper must be imported or accessed on its documented object before you can call it. Start here if the editor is new to you.

Versioned save slots (this.save).

Source: runtime/core/save.js

Versioned save slots on top of localStorage (or any Storage-like object).

constructor(gameId, { version = 1, storage = globalThis.localStorage, migrate = null } = {})

Methods

#slot(n)
Select the numbered save slot. Returns this Save object so calls can be chained.
#get(k, def)
Read a key from the selected slot. Returns the fallback value when the key is absent.
#set(k, v)
Store a JSON-compatible value under the key in the selected slot.
#remove(k)
Remove one key from the current slot.
#all()
Return the selected slot’s complete data object.
#has(n = this.slotId)
Return true if this slot exists in storage. Defaults to the currently selected slot.
#delete(n = this.slotId)
Remove a save slot from storage. Defaults to the currently selected slot.
