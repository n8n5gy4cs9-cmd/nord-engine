Input

Action-based input (this.input).

Source: runtime/core/input.js

Action-based input. Pure state machine; DOM wiring in `attachDom`. Actions map to codes like 'KeyA', 'Space', 'Mouse0', 'Gamepad0' (button 0), 'GamepadLeft'/'GamepadRight'/'GamepadUp'/'GamepadDown' (left stick).

Methods

#setKey(code, down)
Set a physical key’s held state. Normally called by the browser input adapter.
#setVirtual(action, on)
Set a named action’s held state for touch or other virtual controls.
#beginFrame()
Call once per frame before scripts update: snapshots action state so pressed/released work.
#down(a)
Return true while this named action is held.
#pressed(a)
Return true only on the frame the action becomes held.
#released(a)
Return true only on the frame the action stops being held.
#key(code)
Read a physical keyboard code such as KeyW. Returns true while held.
#axis(neg, pos)
Return -1 for the negative action, +1 for the positive action, or 0 when both/neither are held.
#vec(l, r, u, d)
Normalised 2D vector from four actions (analog stick wins when deflected).
#pollGamepad(pad)
Feed gamepad state (navigator.getGamepads()[i]-shaped). Buttons map to 'Gamepad<n>', left stick to Gamepad{Left,Right,Up,Down}.
