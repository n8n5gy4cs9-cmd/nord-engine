API / Nord Engine

NordScript

Base class of every script.

Source: runtime/core/script.js

For dummy developers

Attach your script to an entity. Use start() for setup and update(dt) for ongoing changes. The engine supplies the shortcuts below.

Read your first script · All lifecycle hooks and their arguments

constructor(entity, attrs = {})

Instance fields

FieldMeaning
entityThe entity this script belongs to.
attrsScript attributes after resolving defaults and scene overrides.

Properties

scene read-only
The scene containing this script’s entity.
game read-only
The running game and its shared services.
input read-only
Read the project’s named input actions.
audio read-only
Play sounds and control music.
time read-only
Elapsed time and the latest frame duration, in seconds.
events read-only
Send and receive messages shared by scripts in this game.
ui read-only
Create labels, buttons and other interface elements over the game.
physics read-only
The current project’s physics adapter.
save read-only
Read and write values in the selected save slot.
rng read-only
The game’s seeded random-number generator.

Methods

#log(...a)
Console output with the script name in front; shows in the browser console and in the editor's Console tab.
#warn(...a)
How this method works
warn(...a) { console.warn(`[${this.constructor.name}]`, ...withLoc(a)); }
#error(...a)
How this method works
error(...a) { console.error(`[${this.constructor.name}]`, ...withLoc(a)); }
#tween(target, to, opts)
Animate numeric values toward the supplied target. Returns a function that cancels the animation.
#after(sec, fn)
Run the callback once after the given number of seconds. Returns a cancel function.
#every(sec, fn)
Run the callback repeatedly at the given interval in seconds. Returns a cancel function.
