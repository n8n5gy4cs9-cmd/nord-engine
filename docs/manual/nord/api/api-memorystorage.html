MemoryStorage

For dummies

In-memory storage for Save when browser storage is unavailable or for isolated runs. Use the contents list to find a topic. Code names are case-sensitive; component settings belong to the selected object in the Inspector. Start with Getting started if you have not opened a project yet.

In-memory storage for Save when browser storage is unavailable or for isolated runs.

Source: runtime/core/save.js

Methods

#getItem(k)
Return the stored string, or null if the key is absent.
#setItem(k, v)
Store the value as a string.
#removeItem(k)
Remove this key. Other stored keys stay available.
