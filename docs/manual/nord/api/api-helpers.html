Math & helpers

For dummies

clamp, lerp, remap, vec, ease… Use the contents list to find a topic. Code names are case-sensitive; component settings belong to the selected object in the Inspector. Start with Getting started if you have not opened a project yet.

Small engine-agnostic helpers exported from nord (runtime/core/util.js).

import { clamp, lerp, remap, vec, ease } from 'nord';

Functions

withLoc(a)
clamp(v, a, b)
Keep v between a and b. Returns the nearest boundary when v is outside the range.
lerp(a, b, t)
Blend from a toward b: t=0 gives a, t=1 gives b. Values outside 0–1 extrapolate.
remap(v, a, b, c, d)
Convert v from input range a–b to output range c–d. Do not use an input range with equal endpoints.
deg2rad(d)
Convert an angle in degrees to radians.
rad2deg(r)
Convert an angle in radians to degrees.
angleDiff(a, b)
Return the shortest signed turn from a to b, in degrees.

vec

Array-based vectors (2 or 3 components): vec.add, sub, scale, len, dist, norm, lerp.

Easing

Names for tween({ease}): linear, quadIn, quadOut, quadInOut, cubicIn, cubicOut, cubicInOut, sineInOut, backOut, elasticOut, bounceOut, bounceIn. A function t→t also works.
