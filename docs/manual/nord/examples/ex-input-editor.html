43 · Input actions and the Input editor

For dummies

Edit your project's input map in the Project tab: bind keys by pressing them, add actions, restore the basics. Use the contents list to find a topic. Code names are case-sensitive; component settings belong to the selected object in the Inspector. Start with Getting started if you have not opened a project yet.

Goal: give your game its own controls (like Unity's Input Manager) and read them in scripts.

The basics every project has#

New projects start with: left right up down (WASD + arrows), jump (Space / W / Up), fire (Space / left mouse), interact (E / Enter).

Edit them#

  1. This is Unity's Input Manager. Project tab ▸ (next to Console) scroll to Input Manager (actions and keys).
  2. Click ＋ key next to jump, then press the key you want. Click a key chip to remove it.
  3. ＋ mouse/pad adds Mouse0-2, Gamepad0-3, Shift, Ctrl, Alt.
  4. Type a name and press Add action (for example dash), then press its first key.
  5. Deleted a basic one by accident? Add missing basics brings back only the missing ones and never touches yours. Reset to basics replaces everything.

It is saved in nord.project.json under input.actions, so each project has its own map.

Use them#

File: scripts/Player.js (new file, the whole file)

import { MonoBehaviour, UnityInput as Input, Time } from 'nord';
export default class Dasher extends MonoBehaviour {
  Update() {
    if (Input.GetButtonDown('dash')) this.Translate(3);
    if (Input.GetButton('left')) this.Translate(-5 * Time.deltaTime);
  }
}

Native style: this.input.pressed('dash'), this.input.down('left'), this.input.axis('left', 'right').

Let players rebind#

this.input.actions.dash = ['KeyQ'] at runtime, saved with this.save.set('bindings', this.input.actions); see Options menu.

Keyboard in the editor while playing#

The Game view owns the keyboard once it has focus: Q/W/E/R and other plain keys reach your game, never the editor tools; click another panel to get the editor shortcuts back. Esc releases a locked mouse in the editor (Settings ▸ Game view mouse). See Which platform? for Application.isEditor.
