37 · Starting points by game type

For dummies

Which template, example project and library scripts to start from for platformers, shooters, RPGs, puzzles, racing, tower defense, card games and more. Use the contents list to find a topic. Code names are case-sensitive; component settings belong to the selected object in the Inspector. Start with Getting started if you have not opened a project yet.

Start from a template whenever the game resembles one (nord new my-game -t <template>, or the hub's New project). Templates are complete, small, readable games.

A path through the docs for a first game#

  1. First script, Input, Finding objects.
  2. Pick the template above, run it, and change one thing at a time (speed, colours, a new enemy).
  3. Add systems as you need them: GameManager, health, spawning, UI, audio, saving.
  4. Polish, options, publish.

Every library script is listed with its attributes in the Library catalog.
