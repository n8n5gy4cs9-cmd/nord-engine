Unity-style scripting

Use this page#

This chapter explains unity-style scripting. Open a saved project before following editor steps. Use the topic links below for a specific task; follow Tutorials when you want a complete project to build in order.

If you know Unity, you can write Nord scripts the way you already do. MonoBehaviour, Singleton, GameManager and friends use Unity's names and rules (Awake, Start, Update, coroutines, Instantiate, PlayerPrefs…), on top of the normal Nord script system. Everything here is optional: a plain NordScript (lower-case start()/update()) works side by side in the same project.

For dummy developers

A script is a file with instructions for one object. A MonoBehaviour is the Unity name for "a script that lives on an object and gets Start/Update calls". A Singleton is a script of which there is only ever one, reachable from everywhere by name (Score.instance). A GameManager is a ready-made singleton that keeps score, lives and the game state.

Create a script (3 ways)#

  1. In the Assets tab right-click a folder (for example scripts) ▸ New MonoBehaviour script (Unity-style), New Singleton script or New GameManager script. Type a name and press Enter. The file opens in the Code tab.
  2. Same menu in the Create menu of the Assets tab (the + button).
  3. By hand: make scripts/Player.js and start it with import { MonoBehaviour } from 'nord';.

Attach it to an object#

  1. Select the object in the Hierarchy.
  2. In the Inspector press + Add script and pick your script, or drag the .js file from Assets onto the object (in the Hierarchy or the Scene view).
  3. The script's fields (see SerializeField below) appear in the Inspector under the script's name. Change them there; they are saved in the scene.
  4. Press Play. Errors show in the Console with a clickable file and line.

A script can be on many objects; each gets its own copy and its own field values. A Singleton must be on one object only.

MonoBehaviour: the Unity script#

Assets ▸ Create ▸ MonoBehaviour script gives you this:

File: scripts/Player.js (this is what Assets ▸ Create ▸ MonoBehaviour script creates)

import { MonoBehaviour, SerializeField, Time, WaitForSeconds, UnityInput as Input } from 'nord';

export default class Player extends MonoBehaviour {
  static attributes = SerializeField({ speed: 5, jump: { default: 3, min: 0, max: 10 } });

  Awake() {}                       // once, when the object is created
  Start() {                        // once, before the first Update
    this.StartCoroutine(this.Blink());
  }
  Update() {                       // every frame
    this.Translate(Input.GetAxis('Horizontal') * this.speed * Time.deltaTime);
  }
  OnTriggerEnter(other) {          // a trigger collider was entered
    if (other.CompareTag('coin')) this.Destroy(other);
  }
  *Blink() {                       // a coroutine
    while (true) { this.SetActive(false); yield new WaitForSeconds(0.1); this.SetActive(true); yield new WaitForSeconds(0.4); }
  }
}

Rules: extend MonoBehaviour; use the capitalised Unity names; never mix them with the lower-case Nord names (start, update) in the same class.

Fields: [SerializeField]#

static attributes = SerializeField({ speed: 5, name: 'Bob', alive: true, color: '#ff0000', pos: [0, 0, 0] }) makes Inspector fields. Numbers get drag boxes (add { default, min, max } for a slider), booleans checkboxes, #rrggbb strings colour pickers, 2/3 numbers vectors. Read them as this.speed anywhere in the script.

Lifecycle (in order)#

Method When
Awake() The object and its scripts are created. Set up your own data here.
OnEnable() The object or script becomes active (also after SetActive(true)).
Start() Once, just before the first Update, after every Awake ran. Find other objects here.
FixedUpdate() Fixed 60 times per second. Physics work.
Update() Every frame. Input, movement.
LateUpdate() After all Updates: cameras that follow things.
OnCollisionEnter(other) OnCollisionExit(other) Solid colliders touch / separate.
OnTriggerEnter(other) OnTriggerExit(other) A trigger volume is entered / left.
OnDisable() Switched off.
OnDestroy() The object is removed or the scene ends. Clean up here.

Coroutine yields: null (next frame), new WaitForSeconds(s), new WaitUntil(() => cond), new WaitWhile(() => cond), new WaitForFixedUpdate(), new WaitForEndOfFrame(), or another coroutine (nested).

Static helpers (import from 'nord')#

  • Time: deltaTime, fixedDeltaTime, time, timeScale (settable: 0 pauses, 0.1 slow motion), frameCount.
  • UnityInput (import as Input): GetKey / GetKeyDown / GetKeyUp('Space' | 'KeyA' | 'ArrowLeft' | 'Mouse0'), GetAxis('Horizontal' | 'Vertical') (WASD + arrows + stick), GetButton / GetButtonDown / GetButtonUp('jump') for your project's input actions, GetMouseButton(n), mousePosition.
  • Mathf: PI, Abs, Floor, FloorToInt, Clamp, Lerp, LerpUnclamped, InverseLerp, MoveTowards, SmoothStep, Repeat, PingPong, Approximately, DeltaAngle, LerpAngle, Random.
  • Vector2 / Vector3: zero, one, up, down, left, right, forward, back, Distance, Dot, Cross, Lerp, MoveTowards, magnitude, sqrMagnitude, normalized, Clone, Add, Sub, Mul, Set, Equals, toArray.
  • Debug: Log, LogWarning, LogError, Assert (to the Console). In the editor each line ends with (scripts/file.js:LINE): double-click it in the Console to open that script in the Code tab at that line (errors too, like Unity).
  • PlayerPrefs: GetInt/GetFloat/GetString(key, default), SetInt/SetFloat/SetString, HasKey, DeleteAll (saved in the browser / app).
  • Application: platform (RuntimePlatform.OSXEditor / WindowsPlayer / WebGLPlayer / IPhonePlayer…), isEditor, isDesktopApp, isWebPlayer, isMobilePlatform, os. Cursor: lockState = CursorLockMode.Locked, visible. See Input.
  • SceneManager: LoadScene('scenes/level2.scene.json'), ReloadScene(), sceneName. Application: Quit(), isPlaying.

More Unity helpers (import from 'nord')#

  • KeyCode: Input.GetKey(KeyCode.Space), KeyCode.W, Alpha1, LeftShift, UpArrow, Mouse0, F1… Also Input.GetMouseButtonUp, GetAxisRaw, anyKey, anyKeyDown.
  • Random: Random.Range(0, 10) (two integers = int in [0, 10) like C#), Random.Range(0.5, 1.5) (floats), value, insideUnitCircle, onUnitSphere, insideUnitSphere, Pick(array), InitState(seed).
  • Color: Color.red, new Color(1, .5, 0), Color.FromHex('#ff8800'), Color.Lerp, c.toHex() for tints.
  • More Mathf: SmoothDamp (returns { value, velocity }), Atan, Asin, Acos, Log, Exp. More Vector2/Vector3: Scale, Div, negative, Normalize, Angle, SignedAngle, ClampMagnitude, Project, Reflect, Perpendicular, Min, Max, LerpUnclamped.
  • Time: also unscaledDeltaTime, fixedTime, realtimeSinceStartup; coroutines: WaitForSecondsRealtime.
  • Free functions like Unity: Instantiate(...), Destroy(obj, delay), DontDestroyOnLoad(obj), GameObject.Find / FindWithTag / FindGameObjectsWithTag, UnityObject.FindObjectOfType(MyScript), Screen.width/height, Physics2D.OverlapBox(center, size), Debug.LogFormat.
  • Field helpers: SerializeField({ speed: Range(0, 10, 5), mode: Enum(['idle', 'chase'], 'idle'), target: EntityRef() }).
  • On a MonoBehaviour: localScale, eulerAngles, parent, childCount, GetChild(i), FindChild(name), AddComponent(type), LookAt(target) (2D), isGrounded, velocity / SetVelocity(x, y) (2D physics), print(...), and the mouse events OnMouseDown OnMouseUp OnMouseEnter OnMouseExit OnMouseOver OnMouseDrag OnMouseUpAsButton (pointer over the object's box).

Rotations are Euler degrees (eulerAngles), there is no Quaternion. Vectors have no +/* operators in JavaScript: use a.Add(b), a.Mul(k).

Singleton: one object, reachable everywhere#

Assets ▸ Create ▸ Singleton script:

File: scripts/Score.js (this is what Assets ▸ Create ▸ Singleton script creates)

import { Singleton } from 'nord';

export default class Score extends Singleton {
  static persistent = false;      // true = survives scene loads
  Awake() { this.value = 0; }
  Add(n) { this.value += n; }
}
  1. Put Score on one object in the scene (an empty object named Score is the usual place).
  2. Use it from any script: Score.instance.Add(10). Score.require() does the same but throws a clear error when the script is missing from the scene.
  3. A second copy destroys itself and warns in the Console.
  4. static persistent = true keeps the object when you load another scene (it adds the Persist behaviour), ideal for settings, inventory, music.

GameManager: score, lives, state#

Assets ▸ Create ▸ GameManager script makes export default class extends GameManager {}, a persistent singleton with batteries included. Put it on one object in your first scene.

Member What it does
GameManager.instance the one manager
score, lives, state, data current values (state starts as 'playing')
AddScore(n) adds to score, emits score
SetLives(n) LoseLife() change lives, emits lives; reaching 0 calls GameOver()
SetState(name) 'playing', 'paused', 'gameover' or your own, emits state { state, previous }
GameOver() state 'gameover' and the gameover event with the score
Get(key, default) Set(key, value) free data store, emits data
Pause() Resume() TogglePause() freeze / continue the game
LoadScene(path) Restart() change scene / restart with score and lives reset
SaveHighScore(key) stores the best score (default key highscore) and returns it

Fields in the Inspector: startLives (3) and startState. Listen to its events from anywhere:

File: your script, for example scripts/Hud.js (inside Start())

this.game.events.on('score', ({ score }) => this.label.set(`Score ${score}`));
this.game.events.on('gameover', () => GameManager.instance.LoadScene('scenes/menu.scene.json'));

AudioManager#

A persistent singleton: add AudioManager (import from 'nord' and extend it, or attach a script that is export default class extends AudioManager {}), then AudioManager.instance.PlaySfx('assets/audio/jump.ogg'), PlayMusic(path), StopMusic(), SetVolume('music', 0.5), Mute('sfx').

Events and data#

  • UnityEvent: const onHit = new UnityEvent(); onHit.AddListener(fn); onHit.Invoke(5); (AddListener returns an unsubscribe function).
  • EventBus: EventBus.Subscribe('hit', fn) and EventBus.Publish('hit', data), a global message bus (same bus as this.game.events).
  • ScriptableObject: shared JSON data files: const sword = await ScriptableObject.Load('data/sword.asset.json').
  • ObjectPool: reuse bullets instead of creating them: const pool = new ObjectPool(this.scene, 'prefabs/bullet.prefab.json'); await pool.Warm(10); const b = await pool.Get({ pos }); pool.Release(b);.

Inspector attributes and buttons#

Inside static attributes = SerializeField({ … }) the Unity attributes are helper calls (or the same keys in a field object): Header('Movement', 5), Tooltip('Pixels per second', 5), Space(8, 5), Range(0, 10, 5), TextArea('hello'), ReadOnly(5), HideInInspector(5), Enum(['a', 'b'], 'a'), EntityRef('Name') and Button('Generate', 'Generate'). A button runs the script's static method in the editor on the object that has the script: it receives ctx with ctx.entity, ctx.attrs, ctx.CreateChild(data), ctx.Destroy(child), ctx.Find, ctx.FindAll, ctx.log, and the result is one undo step. A full example that builds the twelve hour indicators of a clock is on page 3.5.

More Unity classes (part 2)#

Import from 'nord'. Full list with what is missing: Unity coverage.

  • Transform, Quaternion (Euler, AngleAxis, LookRotation, Slerp…), Space: this.transform.Translate(Vector3.right.Mul(5), Space.World).
  • Component wrappers through GetComponent: SpriteRenderer (color, flipX, sortingOrder), Rigidbody2D / Rigidbody (velocity, mass, drag, gravityScale, bodyType, AddForce), BoxCollider2D / CircleCollider2D (isTrigger, size, radius), Animator (SetFloat, SetBool, SetTrigger, Play), AudioSource, Camera (Camera.main, orthographicSize, ScreenToWorldPoint), Light, ParticleSystem, TextMesh, MeshRenderer.material.
  • Physics2D (every cast and overlap, Distance, IgnoreCollision, joints, capsule / polygon / composite colliders) and Physics (Raycast, SphereCast, BoxCast, OverlapBox, joints …): see the Unity API pages, starting with Unity API in Nord.
  • OnTriggerStay and OnCollisionStay are called every frame while two objects touch.
  • Input.GetKey("space") (names as well as KeyCode), Input.GetButton("Jump" | "Fire1"), Input.mouseScrollDelta, Input.touchCount / GetTouch.
  • Time.smoothDeltaTime, SceneManager.LoadSceneAsync / GetActiveScene / sceneLoaded, Application.targetFrameRate / persistentDataPath / OpenURL, Resources.Load, JsonUtility, PostProcessing.Add('crt', {…}), Mathf.PerlinNoise.

File: scripts/Walker.js (new file, the whole file; attach it to an object with a sprite and a rigidbody)

import { MonoBehaviour, SpriteRenderer, Rigidbody2D, Color, Physics2D, Vector2, UnityInput as Input } from 'nord';

export default class Walker extends MonoBehaviour {
  Start() {
    this.sprite = this.GetComponent(SpriteRenderer);       // a wrapper around the sprite component
    this.body = this.GetComponent(Rigidbody2D);
    this.sprite.color = new Color(1, 0.8, 0.4, 1);         // tint without touching the texture
  }

  FixedUpdate() {
    const hit = Physics2D.Raycast(this.transform.position, this.transform.right, 40);   // 40 px ahead of the sprite's right side
    const wall = hit.collider !== null;
    this.body.velocity = wall ? Vector2.zero : new Vector2(Input.GetAxis('Horizontal'), 0).Mul(120);
  }
}

Troubleshooting#

  • Nothing happens: the script is not attached, or the object is disabled. Check the Inspector and the Console.
  • "second X found, destroying the duplicate": a Singleton is on two objects (or in two scenes). Keep one.
  • X.instance is null: the Singleton script is not in the current scene, or it runs later than the caller. Use X.require() in Start(), not Awake(), or set persistent = true and put it in the first scene.
  • Method never runs: you used a lower-case name (update) in a MonoBehaviour class or a typo. Use Update.
  • Attributes you added show only after saving the script (the Inspector re-reads it).
