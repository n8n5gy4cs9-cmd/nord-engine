Keyboard shortcuts

For dummies

Editor shortcuts (macOS). Choose the topic that matches your current task. Use the linked editor chapter for setup and check the exact names in the reference before changing project files. Start here if the editor is new to you.

Editor shortcuts on macOS (Ctrl replaces Cmd on other platforms). Also listed in Settings (Cmd+,).

KeysAction
Cmd+PQuick open file
Cmd+KCommand palette
Cmd+SSave
Cmd+Z / Shift+Cmd+ZUndo / redo
Cmd+C / Cmd+V / Cmd+DCopy / paste / duplicate entity
DeleteDelete selection
W / E / RMove / rotate / scale gizmo
FFocus selection in viewport
Cmd+R / Cmd+.Play (toggles stop) / stop — rebind above
Cmd+F / Cmd+Opt+FFind / replace in file
Cmd+Shift+FSearch in project
Cmd+GGo to line
Cmd+/Toggle comment
Tab / Shift+TabIndent / dedent
Ctrl+SpaceAutocomplete
Cmd+1/2/3/4Show Scene / Game / Code / Assets
