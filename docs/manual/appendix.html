Troubleshooting#

Symptom Fix
Blank page after export Folder builds must be served over http. Use python3 -m http.server, or build with --single-file.
3D physics missing on a host Serve .wasm as application/wasm.
No sound Browsers require a click/key first; sounds are queued until then.
Script change not applied Imports of a script are not hot-reloaded — reload the game.
nord check-offline fails A file mentions an http(s):// host. Remove it, or add the host to .offline-allow.
Rust build fails to link rustup target add wasm32-unknown-unknown; for apps install wasm-bindgen-cli at the lock-file version.
Editor webview blank (macOS) Use Open in browser in the Game tab and report it — the embedded webview is the least-tested part (docs/KNOWN_ISSUES.md).

FAQ#

Do I have to learn Phaser or Babylon? No. Nord's API covers them; entity.native is only an escape hatch. Can I use TypeScript? Not yet (planned via esbuild-wasm). Can I make a Windows/Linux app? The web export runs anywhere; nord bundle-mac (macOS) and nord bundle-portable --os windows|linux wrap it with the native player; real desktop apps (files, dialogs, tray…) are covered in Desktop apps. Windows/Linux builds are CI-built; owner verification pending. Where do I report bugs / what is known broken? Known issues. Can I use my own assets? Yes — just keep them under assets/ and make sure you may redistribute them.
