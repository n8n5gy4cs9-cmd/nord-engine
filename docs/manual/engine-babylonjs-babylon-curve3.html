Curve3 #

export class Curve3

A Curve3 object is a logical object, so not a mesh, to handle curves in the 3D geometric space. A Curve3 is designed from a series of successive Vector3. see (online reference)

ArcThru3Points #

static ArcThru3Points(first: Vector3, second: Vector3, third: Vector3, steps?: number, closed?: boolean, fullCircle?: boolean): Curve3;

Returns a Curve3 object along an arc through three vector3 points: The three points should not be colinear. When they are the Curve3 is empty. param first (Vector3) the first point the arc must pass through. param second (Vector3) the second point the arc must pass through. param third (Vector3) the third point the arc must pass through. param steps (number) the larger the number of steps the more detailed the arc. param closed (boolean) optional with default false, when true forms the chord from the first and third point param fullCircle Circle (boolean) optional with default false, when true forms the complete circle through the three points returns the created Curve3
