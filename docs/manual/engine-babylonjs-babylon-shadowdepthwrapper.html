ShadowDepthWrapper #

export class ShadowDepthWrapper

Class that can be used to wrap a base material to generate accurate shadows when using custom vertex/fragment code in the base material

Instantiate a new shadow depth wrapper. It works by injecting some specific code in the vertex/fragment shaders of the base material and is used by a shadow generator to generate the shadow depth map. For more information, please refer to the documentation: (online reference) param baseMaterial Material to wrap param scene Define the scene the material belongs to param options Options used to create the wrapper
