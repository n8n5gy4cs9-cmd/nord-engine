### Native FPS mouse capture regression

`./run.sh <disposable FPS template project>` → main Play → Click to play: free mouse movement turns the camera without a held button, Esc pauses/releases, Resume recaptures. Stop main Play, FPS Level → Open… → level1.fpsl.json → Test → Click to play: repeat capture, then Shift+Esc returns to editing. Check actual `document.pointerLockElement === canvas` with a temporary DOM probe when diagnosing host support; remove the probe afterward. Chromium tests alone cannot verify the WKWebView permission delegate. Rust grant-policy check: `cargo test -p nord-editor --features webview --lib only_focused_loopback_content_can_capture`.

### 2D Level Creator and Machine Workshop

`node --test editor/level2d/model.test.mjs` verifies every catalogue source hash/unique ID, flood boundaries, scene compilation, hidden/collision layers, body fields, mode settings and undo. `cargo test -p nord-core level2d` checks traversal and symlink ancestors. `node tools/level2d-test.mjs` uses the real `nord serve`, a disposable workshop project and Chromium: bank pagination, pointer paint/undo/redo, physics-object placement, asset/script publication, CSRF/path guards, actual platform/top-down movement, scaled colliders/floor contact, Stop, Matter gravity/round bodies, the default machine solution, normal offline build. Screenshots: `target/level2d/`. Set `PW_CHROMIUM` only when a local Playwright/browser version mismatch requires an explicit executable. These suites run in `js-e2e` CI. Owner still verifies the native embedded 2D Level tab, keyboard focus and Windows feel.

`node --test tools/creator-games.test.mjs` checks dungeon hit/armor/path/sight rules, tank collision/team rules and compilation of every authored map. `node tools/creator-games-test.mjs` runs the real server and Chromium: keyboard dungeon movement, bump combat, key/door, saved stairs transition and inventory carry, relic victory, authoring Save with its custom controller; tank input/AI, actual shells breaking cover and destroying tanks, victory/restart; both project offline builds and actual exported-game boot on standalone static servers with no engine fallback (including the exported second-floor transition). Deterministic combat RNG and immobilized enemy targets are used only in the relevant test phases; the separate AI phase checks real motion. Screenshots: target/creator-games/. M12-30 tutorial screenshots are copied to docs/screenshots/ed-creator-*.png.

M12-31 / BUG-010: `node --test editor/level2d/items.test.mjs` verifies preset persistence/copy isolation. `node tools/level2d-placement-test.mjs` reproduces real Items → Brush and palette drag/drop across platform, top-down, machine, dungeon and tanks; dungeon checks cell alignment, per-stroke undo, save/reopen and live actor registration. This is separate from selecting the E Object tool. Included in js-e2e CI.

`editor/level2d/view.test.mjs` covers fit before ResizeObserver has measured the native/browser pane and zero-size layout deferral. The placement browser suite reloads the saved map and requires another working Brush click; merely seeing the map or counting previously saved objects is insufficient to catch NaN world coordinates.

### Advanced coding workshops T35–T37

`node --test tools/advanced-workshops.test.mjs` checks pure Node game rules. `rustc --test examples/rust-salvage/src/sim.rs -o /tmp/salvage-tests && /tmp/salvage-tests` checks the production Rust simulation without a window. `nord build examples/rust-salvage --target web-wasm-game --out target/e2e/advanced-salvage` builds the actual WASM export. Then `NORD_SALVAGE_EXPORT="$PWD/target/e2e/advanced-salvage" node tools/advanced-workshops-test.mjs --manual` checks shader compilation/controls/restart, real Node HTTP validation and cross-origin browser completion/leaderboard, the WASM render/input/pause HUD, and CodeMirror/source/image/download behavior for all three guides. PW_CHROMIUM is supported for installed-browser overrides. Full human balance/native-host walkthroughs remain separate. These checks are in js-e2e CI.
