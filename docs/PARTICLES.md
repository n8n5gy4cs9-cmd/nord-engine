# Particles (M10-20)
Editor tab **Particles** edits the selected entity's `particles` component (add it with one click): presets (fire, smoke, sparks, explosion, rain, snow, magic, hit, dust, coin, confetti), emission (rate, quantity, burst, spawn radius, lifespan), motion (speed, angle, gravity x/y, spin), look (scale and opacity as start→end **or an editable curve** with 2–8 points over the particle's life, start/end colour gradient, additive blending) and a **live preview** (CPU simulation, approximate — tune the look, then check in the game). Changes undo like any edit. Code: `crates/nord-editor/src/particles.rs` (model + simulation, tested), `panels/particles.rs`.
Component fields (runtime `runtime/phaser/components.js`): `texture, lifespan (ms), speed [min,max], angle [min,max], scale [start,end], alpha [start,end], scaleCurve [..], alphaCurve [..], gravityX, gravityY, tint, tintEnd, spin (deg/s), emitRadius, frequency (ms), quantity, burst, emitting, blend ("add"|"normal")`; script/event access: `comp.burst(n)`, `comp.start()`, `comp.stop()`. Test: `tools/plugin-objects-test.mjs` (curves/gradient/spin/zone in WebGL), `particles_panel_…` kittest.
Not done: emission shapes other than a disc, per-particle texture frames, collision with tiles, a library of saved custom presets (copy the component JSON; the library script `fx-particle-presets` has named presets).
