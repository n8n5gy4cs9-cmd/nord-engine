# FPS arena
Click the game to capture the mouse (cursor hidden; Esc releases it) — script `mouse-capture.js`. WASD move, Shift sprint, C crouch, Space jump, Left mouse / F fire. Shoot all 10 targets (3 hits each).
Library: `fps3d`, `physics-hitscan`, `physics-crate`. Own script: `arena.js` (HUD + win).
