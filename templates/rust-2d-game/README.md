# Rust 2D game (Nord)
`src/main.rs` holds your scripts; `scenes/`, `assets/` work exactly like the JS tier. In the editor press ▶ Play (it builds first) or run
`nord build-rust` then `nord serve .`; export with `nord export . --target web-wasm-game`. See docs/RUST_TIER.md in the engine repo.
Needs `rustup target add wasm32-unknown-unknown`.
