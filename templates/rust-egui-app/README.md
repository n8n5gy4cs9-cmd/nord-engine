# Rust egui app (Nord)
Edit `src/main.rs`. ▶ Play in the editor (or `nord build-rust` + `nord serve .`) runs it in the browser; `nord export . --target web-wasm-app` writes a static site.
Needs the wasm32 target and the `wasm-bindgen` CLI (same version as the crate in Cargo.lock). See docs/RUST_TIER.md.
