# fpsc/ — your FPS Creator content

- `bank.json` registers your own textures, wall pieces, entities, sounds and scripts.
- `textures/`, `art/` (sprites), `models/` (.glb), `sounds/`, `scripts/` hold the files.
- Levels live in `../levels/*.fpsl.json`. Edit them with the **FPS Level** tab (or open /editor/fpsc/index.html on `nord serve`).
- The runtime is `../scripts/fpsc/` — run `nord fpsc init` after updating Nord to upgrade it (your files here are never touched).

Full guide: docs/FPS_CREATOR.md.
